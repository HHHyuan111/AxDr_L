# 03 开发总验收方案（供独立验收 AI 使用）

> 用途：开发全部完成后，由负责人安排的**独立 AI** 按本文件验收开发成果。
> 本文件只描述"最终状态必须满足什么、如何检查"，不描述开发过程。
> 判定分三档：**通过 / 有条件通过（列出全部偏差）/ 不通过**。任何一项不通过即整体不通过；
> 有条件通过只用于"数值偏差可量化且负责人可接受"的情形，由负责人最终裁定。

## 0. 验收材料与前置条件

验收 AI 需要拿到：

1. 本仓库最终状态（`C:/Users/ready/Desktop/DriverLab/AxDr_L`，分支 `codex/firmware-validation` 或负责人指定分支）；
2. 三份规范文件：`firmware/AxDr_App/00_开发总规范.md`、`01_开发约束细则.md`、`02_架构决策与状态机规范.md`；
3. 本验收方案；
4. 各阶段验收证据目录（`artifacts/` 下对应阶段子目录，含 host 日志、Keil 构建日志、RAM 记录、真机实验记录）；
5. 真机验收项需要板卡与操作员配合，验收手册式步骤见各 [真机] 项。

验收基线：冻结提交 `c669dcd`（速度环真机验收通过的版本）。**行为不变类改动**必须证明最终行为与基线一致；
**功能新增类**按本文件各 D 项逐项验收。

标签含义：[离线] 验收 AI 可独立执行；[真机] 需要板卡 + 操作员；[人工] 需要负责人判断或提供输入。

## A. 规范符合度（00/01/02 三份文件逐条检查）

| 编号 | 检查项 | 方法（机械步骤） | 通过标准 |
|---|---|---|---|
| A1 | 依赖方向铁律 | 按 00 §2.1 七层表，把每个 User/*.c 的 include 逐条归层，列出所有"向高层/同层 include" | 违规数 = 0（例外需在代码中显式注释并获负责人批准） |
| A2 | 零新增全局变量 | grep 全部 User/*.c 文件级定义：`grep -nE "^[a-zA-Z_].*;" *.c` 人工过滤 | 除 `g_foc`（foc_drv.c）外无任何文件级可写变量；常量表须 `static const` |
| A3 | 算法核零硬件依赖 | `grep -riE "hal_|stm32|main\.h" User/algorithm User/control User/diagnostic/core` | 命中数 = 0 |
| A4 | 命名规范 | 抽查新公开函数：`grep -nE "^[a-z_]+ [a-z_]+\\("` 对照 01 §4 | 公开函数带模块前缀；枚举/宏大写带前缀；无 flag/data/info 泛词字段 |
| A5 | float 单精度 | `grep -rn "double" User/ --include="*.c" --include="*.h"`（排除注释与 "double" 出现在英文词中的情形） | 命中数 = 0；字面量带 f |
| A6 | 积分器规则 | 读 PID 实现（algorithm/control_pid.c），检查积分项状态形式 | 状态存"未乘 ts 的和"，输出时乘 ts；dt 只出现在一处 |
| A7 | 注释黑名单 | `grep -rnE "不是|不能|不负责|并不会|需要说明|值得注意的是|换句话说" User/` | 命中数 = 0（"避免/防止 + 原因"句式允许） |
| A8 | 算法三件套 | 对新增算法模块逐文件检查 | init/reset/tick 齐全；状态全在对象结构体；文件头声明来源/单位/上下文/无动态内存 |
| A9 | 参数三居所 | 新增可调参数对照 00 §4.1 | 类型在算法 .h；值在默认档案一处；带来源注释 |
| A10 | 错误处理三级 | 抽查新增失败路径 | ret_e 检查完整；故障走位图；配置矛盾用 _Static_assert |
| A11 | 验收门证据 | 检查 artifacts/ 各阶段证据 | 每阶段有 host 日志、Keil 0E0W 日志、RAM 记录、真机记录（真机项） |
| A12 | 提交规范 | `git log --oneline` 抽查开发期提交 | 信息格式 `<层>: <中文一句话>`；无混入批量格式化 |

## D. 功能完成度（每个功能一个验收实验）

通用要求：每项实验记录原始数据（波形文件/日志/截图）进 artifacts；通过标准是**数值门限**，不是"页面能点"。

| 编号 | 功能 | 实验步骤（摘要，详见各阶段验收手册） | 通过标准（默认值，负责人可调） |
|---|---|---|---|
| D1 | VF 开环强拖 | [真机] 经上位机 SET_VF：0→设定频率斜坡启动；正转/反转；改频率跟随；STOP；断连自动停机 | 设定 2~10 Hz 内实测转速误差 < ±5%；斜坡无冲击；STOP 后 3 拍内关 PWM；断连后 fail-closed 停机；波形无畸变 |
| D2 | IF 开环电流 | [真机] SET_IF：电流给定阶跃 0.5→2 A；虚拟角度匀速；STOP | 电流跟随误差 < ±5% 满量程；角度线性推进；无失步；停机立即 |
| D3 | 电流闭环 | [真机] SET_CURRENT：小目标跟随、阶跃、限幅验证、STOP | 阶跃上升时间与整定带宽一致（500 rad/s 设计值 ±20%）；稳态误差 < ±2%；限幅生效 |
| D4 | 速度闭环 | [真机] SET_SPEED：分档目标（含正反转）、斜坡、限幅、负载扰动观察 | 稳态误差 < ±1%；斜坡跟踪误差 < ±5%；方向守卫不误报、真反向能报 enc_err |
| D5 | 位置闭环 | [真机] SET_POSITION：小目标、正反向、速度/电流限制生效、STOP、模式切换 | 到位误差 < ±0.05 rad；限幅生效；切换不产生冲击 |
| D6 | 无感（中速段速度控制） | [真机] 按 S5 验收手册：编码器对照时间对齐 → I/F 起动 → 平滑切换 → 失锁停机 | 中速段（约定区间，负责人定）估计误差 < ±5%；切换无电流冲击；失锁 100 ms 内停机；全程记录快环耗时 |
| D7 | 上位机一致性 | [离线+真机] 能力位、模式状态、参数读写、波形通道与固件语义逐项对照 | 协议按 02 §7：只增不改；宿主按长度兼容；固件回报与实际行为一致；参数回读 = 写入值 |
