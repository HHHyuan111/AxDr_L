# 第一阶段可重复构建基线

日期：2026-08-27

## 1. 本阶段目标

本阶段只建立一个可追溯、可重复构建的开发起点，不重构控制算法，不调整电机参数，不改变外设时序，也不处理尚未完成的 Elmo 工装。

原始源码目录保持只读：

`D:\Axdr_Driver-lab\AxDr原始代码\AxDr_L-main\AxDr_App`

后续开发使用受控副本：

`D:\Axdr_Driver-lab\Driver_lab\firmware\AxDr_App`

## 2. 原始基线核对

- 从原始工程选择 195 个源码、配置和必要工程文件，共 9,002,556 字节。
- 排除旧构建产物、IDE 用户配置、J-Link 日志及临时文件。
- 首次导入内容已逐文件与原始目录的 Git 对象哈希核对，195 个文件全部一致，差异为 0。
- 原始目录未被修改；后续修复只发生在 `Driver_lab` 受控副本中。
- 用户要求剔除的“代码架构预研”文件夹或文件不作为本阶段开发输入。

## 3. 为恢复构建所做的最小修改

1. 在顶层 CMake 中补入 `User/moldue/inc` 头文件目录。
2. 用明确的源文件清单替代递归扫描，固定当前参与构建的 BSP、显示/VOFA 和电机控制源文件。
3. 修正 MA732 SPI 接收数组的指针类型，使其符合函数参数声明；数据缓冲区和调用时序不变。
4. 四个中文字库当前没有有效字模。为满足 C11 对数组定义的要求，各加入一个全零占位项，并在计数时减去该项，运行时有效字模数量仍为 0。
5. 增加构建后的 HEX 生成和镜像尺寸输出，最终同时得到 ELF、HEX 和 MAP。
6. 在工具链文件中加入一次性加载保护，去除 CMake 重复读取工具链造成的重复编译参数。

本阶段没有修改控制公式、控制周期、中断入口、外设初始化、通信协议或标定参数。

## 4. 构建环境

- CMake：4.4.2
- Ninja：1.13.2
- ARM GNU 工具链：16.1.0
- 工具链目录：`D:\EmbeddedControlTools\MSYS2\ucrt64\bin`
- 目标芯片：STM32G474RETx，Cortex-M4F，硬件单精度浮点

在固件目录执行：

```powershell
$env:Path = "D:\EmbeddedControlTools\MSYS2\ucrt64\bin;$env:Path"
cmake --preset Debug --fresh
cmake --build --preset Debug
cmake --preset Release --fresh
cmake --build --preset Release
```

## 6. 当前未处理项

以下问题已经被编译器暴露，但不在本阶段顺手修改，避免把“恢复构建”扩大成算法重写：

- `main.c`、`foc_calc.c`、`eh_observer.c` 等处存在未初始化变量警告，下一阶段应优先确认其真实意图并消除未定义行为。
- `M_PI`、`M_2_PI` 与工具链数学头文件重名。
- 部分 BSP 存在指针与整数比较、枚举比较和返回值初始化问题。
- 现有代码还有未使用变量、未覆盖分支等一般警告。
- 链接器提示 ELF 含可读、可写、可执行的段，需要结合链接脚本和 RAM 函数布局单独验证。
- 本机 Keil 已安装，但工程指定的 `Keil.STM32G4xx_DFP.2.0.0` 软件包缺失，因此 Keil 全量构建暂记为阻塞，不能拿旧产物代替验证。
- 本节点只建立主机侧编译基线，尚未执行下载、上电和电机运行验证。
