# 三相 PWM 板级适配

日期：2026-08-28

## 1. 本节点做什么

把三相 PWM 的 TIM1 硬件操作从电机控制文件中移到板级适配文件中。控制算法、状态机、相序和占空比计算均不修改。

改动后的调用关系：

`FOC 计算占空比 -> 原有 FOC 接口完成相序映射 -> target_pwm 执行 TIM1 操作`

本节点不处理 ADC、编码器、保护逻辑和观测器算法。

## 2. 具体改动

1. 新增 `target_pwm.h` 和 `target_pwm.c`，集中负责 TIM1 三相 PWM 的启动、停止和占空比写入。
2. 保留 `foc_pwm_start`、`foc_pwm_stop`、`foc_pwm_run` 和 `foc_pwm_duty_set` 原接口，避免影响上层状态机。
3. 删除控制层中已经不再需要的 PWM 寄存器宏。
4. 占空比提交函数继续放在 `.RamFunc`，保持实时链路的 RAM 执行属性。

相序映射保持如下：

| 工作情况 | TIM1 通道 1 | TIM1 通道 2 | TIM1 通道 3 |
| --- | --- | --- | --- |
| ABC 相序 | A 相占空比 | B 相占空比 | C 相占空比 |
| ACB 相序 | A 相占空比 | C 相占空比 | B 相占空比 |
| 预充设置 | 50% | 50% | 50% |

## 3. 验证结果

- Debug 全量构建通过，ELF、HEX、MAP 齐全。
- Release 全量构建通过，ELF、HEX、MAP 齐全。
- 工程仍保留原有 103 条一般告警，本次修改文件没有新增告警。
- `target_pwm_commit_channel_duty` 在 Debug 和 Release 的 MAP 中都位于 `.RamFunc`。
- 用户代码中的 TIM1 三相启停和 CCR1/CCR2/CCR3 写入已集中到 `target_pwm.c`。
- TIM1 通道 4 的 ADC 触发设置保持原样。

## 4. 本节点结论

三相 PWM 已建立第一条可工作的板级适配边界，上层行为保持不变。当前没有连接硬件，因此本节点只确认源码边界和构建结果，不代表已经完成示波器波形验证。
