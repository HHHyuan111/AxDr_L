# PWM 模块中文导读与可读性整理

日期：2026-08-28

## 1. 本节点目标

本节点只提高三相 PWM 代码的教学可读性，不改变占空比算法、相序映射、TIM1 配置、状态机和硬件输出关系。

## 2. 整理内容

1. 在 `target_pwm.h` 开头写明模块输入、输出、调用时机和职责边界。
2. 为启动、停止和占空比设置接口补充较详细的中文功能说明。
3. 将含义不直观的 `target_pwm_commit_channel_duty` 改名为 `target_pwm_set_duty_ratios`。
4. 参数名增加 `ratio`，明确传入值是 `0.0f～1.0f` 的归一化比例，不是定时器计数值。
5. 将占空比写入过程整理为三个可直接阅读的步骤：读取周期、换算比较计数、写入 CCR。
6. 在 `foc_drv.c` 中写明各函数的调用来源、相序映射和硬件适配关系。

## 3. 保持不变的行为

- ABC 相序仍按 A、B、C 写入 TIM1 通道 1、2、3。
- ACB 相序仍按 A、C、B 写入 TIM1 通道 1、2、3。
- start 状态中的三路固定设置仍为 50%。
- 相序无效时仍不更新本周期占空比。
- 板级适配层仍不增加占空比限幅或状态判断。

## 4. 验证结果

- Debug 和 Release 构建通过，ELF、HEX、MAP 齐全。
- `target_pwm_set_duty_ratios` 在两种配置下均位于 `.RamFunc`。
- 用户代码中的 TIM1 三相启停和 CCR1、CCR2、CCR3 写入仍只存在于 `target_pwm.c`。
- `git diff --check` 通过。

当前没有进行硬件波形验证，本节点结论只覆盖代码表达、构建结果和硬件操作归属。
