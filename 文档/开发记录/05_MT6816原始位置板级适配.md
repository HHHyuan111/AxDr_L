# MT6816 原始位置板级适配

日期：2026-08-28

## 1. 本节点目标

把当前实际启用的 MT6816 原始位置读取从电机代码移到板级适配层，使电机位置层不再关心 SPI1、片选引脚、寄存器命令和响应拼接。

改动后的数据流：

`MT6816 -> target_encoder 读取 14 位原始计数 -> encoder 保存新数据 -> pos_calc 换算机械角和电角度`

本节点只处理 MT6816，不迁移 MA732、MT6825 和 DM485，也不修改位置算法。

## 2. 硬件读取关系

| 步骤 | 保持的原有行为 |
| --- | --- |
| 第 1 帧 | 片选拉低，发送 `0x8300`，接收寄存器 0x03 响应，片选拉高 |
| 第 2 帧 | 片选拉低，发送 `0x8400`，接收寄存器 0x04 响应，片选拉高 |
| 数据拼接 | 取两帧响应低 8 位，拼成 16 位后右移 2 位 |
| 输出范围 | 14 位原始位置计数 `0～16383` |

## 3. 具体改动

1. 新增 `target_encoder.h` 和 `target_encoder.c`。
2. `target_encoder_transfer_word` 负责一次带独立片选的 SPI1 16 位通信。
3. `target_encoder_read_mt6816_raw` 负责读取两个寄存器并返回 14 位原始计数。
4. 原有 `read_mt6816_raw` 保留，只负责保存原始值并设置新数据标志，避免扩大调用链修改范围。
5. 两个新增适配函数均放在 `.RamFunc`。

## 4. 保持不变的行为

- SPI1 配置、通信命令、片选顺序和超时计数不变。
- 原始计数拼接公式不变。
- `rev_flag` 的设置和原始值保存位置不变。
- `raw × 2π/16384` 的机械角换算不变。
- 零位、极对数、电角度、跨零计圈和减速比计算不变。
- ADC 实时中断中的编码器读取顺序不变。

## 5. 验证结果

- Debug 构建通过：`text 184,836 B`、`data 136 B`、`bss 10,200 B`。
- Release 构建通过：`text 145,668 B`、`data 136 B`、`bss 10,192 B`。
- `target_encoder_transfer_word` 和 `target_encoder_read_mt6816_raw` 在两种配置中均位于 RAM 地址区。
- 当前 MT6816 上层读取函数不再直接访问 SPI1 和片选 GPIO。
- `git diff --check` 通过。

当前尚未连接 MT6816 硬件，因此本节点只完成源码边界和编译验证。原始计数范围、角度方向、零位和实时通信稳定性仍需后续上板确认。
