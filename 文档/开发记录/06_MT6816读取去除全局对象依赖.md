# MT6816 读取去除全局对象依赖

日期：2026-08-28

## 1. 本节点目标

让 MT6816 上层读取函数显式接收需要更新的编码器对象，不再在函数内部暗中修改全局 `pm`。

修改前：

```c
read_mt6816_raw();
```

修改后：

```c
read_mt6816_raw(&pm->pos_box.mt6816);
```

## 2. 具体改动

1. `read_mt6816_raw` 的参数改为 `enc_para_t *enc`。
2. 原始计数和新数据标志改为写入调用者传入的 `enc`。
3. 原返回值没有调用者使用，因此返回类型由 `uint32_t` 改为 `void`。
4. 单编码器和双编码器分支中的三个 MT6816 调用点均显式传入对应对象。

## 3. 保持不变的行为

- MT6816 底层 SPI 读取方式不变。
- 14 位原始计数的保存字段不变。
- `rev_flag` 仍在每次读取后置位。
- 原始计数到机械角、电角度和多圈位置的算法不变。
- 实时中断中的调用顺序不变。
- MA732、MT6825 和 DM485 的现有代码不修改。

## 4. 验证结果

- Debug 构建通过：`text 184,852 B`、`data 136 B`、`bss 10,200 B`。
- Release 构建通过：`text 145,668 B`、`data 136 B`、`bss 10,192 B`。
- 所有 `read_mt6816_raw` 调用点均显式传入编码器对象。
- `read_mt6816_raw` 仍位于 RAM 地址区。
- `git diff --check` 通过。

本节点只消除当前 MT6816 读取路径中的一个全局对象依赖，不代表整个编码器模块已经完成解耦。
