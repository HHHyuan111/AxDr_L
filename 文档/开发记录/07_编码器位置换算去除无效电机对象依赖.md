# 编码器位置换算去除无效电机对象依赖

日期：2026-08-28

## 1. 本节点目标

去掉 `pos_encoder_calc` 中从未使用的完整电机对象参数，使函数只接收真正需要的编码器对象。

修改前：

```c
pos_encoder_calc(x1, pm);
```

修改后：

```c
pos_encoder_calc(x1);
```

## 2. 具体改动

1. 删除 `pos_encoder_calc` 的 `pmsm_t *pm` 参数。
2. 将含义不明确的参数名 `x` 改为 `enc`。
3. 更新函数声明和两个调用点。
4. 增加中文说明，明确函数输入为原始计数和换算系数，输出为一圈内机械角度。

## 3. 保持不变的行为

- 机械角度仍按 `(raw + off_interp) × factor` 计算。
- 当前 LUT 补偿仍未启用，`off_interp` 继续保持为 0。
- `wrap_0_2pi` 角度整理逻辑不变。
- 编码器读取、零位、电角度和多圈位置计算不变。
- 函数仍位于 `.RamFunc`。

## 4. 验证结果

- Debug 构建通过：`text 184,844 B`、`data 136 B`、`bss 10,200 B`。
- Release 构建通过：`text 145,676 B`、`data 136 B`、`bss 10,192 B`。
- 两个调用点均只传入编码器对象。
- `pos_encoder_calc` 在 Debug 中位于 RAM 地址区。
- `git diff --check` 通过。

本节点只缩小函数依赖范围，没有启用或删除编码器 LUT 补偿功能。
