# 位置反馈主调用链可读性整理

日期：2026-08-28

## 1. 本节点目标

让 ADC 实时控制回调中的位置反馈流程可以按职责直接阅读，同时缩小编码器采样函数的参数范围。

整理后的主链：

```c
encoder_sample(&pm.pos_box);
position_update(&pm);
foc_adc_sample(&pm);
foc_para_calc(&pm);
pmsm_state_ctrl(&pm);
```

## 2. 具体改动

1. `send_encoder_read_command` 改名为 `encoder_sample`，明确函数会完成编码器采样。
2. `encoder_sample` 只接收 `pos_box_t`，不再接收完整电机对象。
3. 无传感器模式明确写出“不读取物理编码器”的分支。
4. `pos_calc` 改名为 `position_update`，明确函数负责更新位置反馈。
5. `x1/x2` 改为 `primary_enc/secondary_enc`，明确主、副编码器关系。
6. 实时回调按位置、ADC、公共参数和状态控制四个阶段补充中文说明。
7. 删除一条原来重复的位置更新函数声明。

## 3. 保持不变的行为

- 实时回调中的执行顺序不变。
- 当前 MT6816 的读取和原始计数保存方式不变。
- 单编码器和双编码器的原有分支逻辑不变。
- NLOB、ALOB 和 SCVM 观测器调用不变。
- 机械角、电角度、多圈位置和控制算法不变。
- 没有增加新的保护或状态判断。

## 4. 验证结果

- Debug 构建通过：`text 184,844 B`、`data 136 B`、`bss 10,200 B`。
- Release 构建通过：`text 145,668 B`、`data 136 B`、`bss 10,192 B`。
- `encoder_sample` 和 `position_update` 在 Debug 中均位于 RAM 地址区。
- 旧名称 `send_encoder_read_command` 和 `pos_calc` 已无代码引用。
- `git diff --check` 通过。

本节点只整理位置反馈主调用链的表达，没有改变位置算法行为。
