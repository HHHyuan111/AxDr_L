# 单编码器位置换算中文导读与可读性整理

日期：2026-08-29

## 1. 本节点目标

把当前实际运行的单编码器位置换算函数整理成可以按步骤直接阅读的代码，同时保持全部位置公式不变。

## 2. 具体改动

1. `sensory1_pos_calc` 改名为 `position_update_single_encoder`。
2. 局部变量 `x/y` 改为 `foc/motor_para`。
3. 按以下五个阶段增加中文说明：
   - 判断单圈角度跨零并累计转子圈数；
   - 机械角乘极对数并加入电角零位；
   - 计算转子单圈和多圈位置；
   - 经过减速比换算输出轴位置；
   - 把累计机械角换算成完整机械圈数。
4. 单行跨零判断改成带大括号的清晰写法。
5. 删除原本已经注释、没有参与编译的读取延迟补偿代码，保留当前未启用状态。

## 3. 保持不变的行为

- 跨零阈值仍为 `0.88 × 2π`。
- `rev` 的正反向累计规则不变。
- `e_pe` 和 `p_e` 的原有计算公式不变。
- `e_off`、`r_off` 和 `m_off` 三个零位的使用位置不变。
- 减速比、单圈位置、多圈位置和机械圈数公式不变。
- 双编码器和无传感器位置计算不修改。

## 4. 验证结果

- Debug 构建通过：`text 184,844 B`、`data 136 B`、`bss 10,200 B`。
- Release 构建通过：`text 145,668 B`、`data 136 B`、`bss 10,192 B`。
- 两种配置的镜像尺寸与上一提交完全相同。
- `position_update_single_encoder` 在 Debug 中位于 RAM 地址区。
- 旧名称 `sensory1_pos_calc` 已无代码引用。
- `git diff --check` 通过。

本节点只提高当前单编码器位置换算的可读性，没有修改位置算法。
