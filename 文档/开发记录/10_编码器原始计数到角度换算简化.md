# 编码器原始计数到角度换算简化

日期：2026-08-29

## 1. 本节点目标

让编码器原始计数到单圈机械角的代码直接表达当前真实算法，移除未生效的 LUT 注释空壳。

## 2. 具体改动

1. `pos_encoder_calc` 改名为 `encoder_update_angle`。
2. 当前算法简化为 `pos = raw × factor`，继续执行 `wrap_0_2pi`。
3. 删除没有实际使用的 `index/off_1/off_2/off_interp` 和无效注释代码。
4. 保留 `enc_table`、`enc_lut`、`shift_bit` 和校准模块，后续单独设计 LUT 接入。

## 3. 验证结果

- Debug 构建通过：`text 184,820 B`、`data 136 B`、`bss 10,200 B`。
- Release 构建通过：`text 145,660 B`、`data 136 B`、`bss 10,192 B`。
- `encoder_update_angle` 位于 RAM 地址区。
- 当前换算结果保持为 `raw × 2π/cpr`。
- `git diff --check` 通过。

本节点没有启用或删除编码器校准表功能。
