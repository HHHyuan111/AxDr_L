# 编码器初始化去除全局对象依赖

日期：2026-08-29

## 1. 本节点目标

让 `encoder_init` 显式接收位置反馈对象，不再在函数内部暗中修改全局 `pm`。

修改后调用：

```c
encoder_init(&pm.pos_box);
```

## 2. 具体改动

1. `encoder_init` 参数改为 `pos_box_t *pos_box`。
2. MA732、DM485 和 MT6816 的参数均写入传入对象。
3. 增加中文说明，明确本函数只设置软件参数，不读取编码器硬件。
4. 整理缩进和空格，不改变参数数值及公式。

## 3. 验证结果

- Debug 构建通过：`text 184,796 B`、`data 136 B`、`bss 10,200 B`。
- Release 构建通过：`text 145,644 B`、`data 136 B`、`bss 10,192 B`。
- `encoder_init` 内不再访问全局 `pm`。
- 编码器方向、位数、CPR、`shift_bit` 和 `factor` 数值不变。
- `git diff --check` 通过。

本节点只缩小初始化函数的依赖范围，没有修改编码器选择和运行算法。
