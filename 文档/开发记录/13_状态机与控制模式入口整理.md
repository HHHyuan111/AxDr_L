# 状态机与控制模式入口整理

## 本节点目标

本节点一次整理“反馈已经准备好以后，程序怎样选择控制模式并进入 FOC”的完整入口。

只调整调度层的命名、注释和排版，不修改位置环、速度环、电流环、轨迹规划、标定、辨识或观测器算法。

## 当前快速控制主链

```text
ADC 注入转换完成
        ↓
读取编码器并更新位置
        ↓
读取 ADC 并换算三相电流
        ↓
更新母线、限幅、转矩和速度反馈
        ↓
运行 PMSM 状态机
        ↓
执行当前选定的控制模式
        ↓
进入电压、电流、速度或位置 FOC
        ↓
SVM 计算成功后提交三相 PWM
```

主入口中的真实执行顺序没有改变。

## 状态机负责什么

原函数 `pmsm_state_ctrl()` 改名为：

```c
pmsm_run_state_machine(pm);
```

这个函数每个快速控制周期运行一次，根据 `ctrl_bit` 处理三种请求：

### start：启动

```text
启动 PWM
  → 写入中点占空比
  → 清空各级控制器
  → 根据故障状态进入预充或故障状态
```

### reset：复位

```text
停止 PWM
  → 清空各级控制器
  → 根据故障状态进入停止或故障状态
```

### opera：运行

```text
执行当前控制模式
  → 再判断本周期故障
  → 进入运行或故障状态
```

这里保留了原工程“先执行本周期控制，再判断故障”的顺序，没有在可读性整理中改变安全行为。

## 模式入口负责什么

原函数 `pmsm_mode_ctrl()` 改名为：

```c
pmsm_run_selected_mode(pm);
```

它只负责把当前模式分派到原有函数：

| 系统模式 | 子模式 | 原有处理函数 |
| --- | --- | --- |
| 对外运行 | MIT | `pm_mit_mode()` |
| 对外运行 | PT/PV/PP | `pt_tor_mode()` / `pv_vel_mode()` / `pp_pos_mode()` |
| 对外运行 | CST/CSV/CSP | `cst_tor_mode()` / `csv_vel_mode()` / `csp_pos_mode()` |
| 停车 | 快速停车/故障停车 | `pmsm_quick_stop_mode()` / `pmsm_fault_stop_mode()` |
| 标定辨识 | 编码器标定/电机辨识/齿槽转矩标定 | 对应原有标定或辨识函数 |
| 实验控制 | V/f、I/f、电压、电流、速度、位置控制 | 对应原有 FOC 函数 |

旧工程中的 `debug_mode` 实际上是实验控制路径，会直接选择功率控制算法，并不是日志或显示开关。本节点只把这一事实写清楚，没有改变枚举值、默认模式或映射关系。

没有实现的模式仍保持空操作，不会擅自补 PWM、停机或故障处理。

## 命名收口

按照本项目约定，跨模块函数名保持清楚，函数内部采用电机控制中常见的科学缩写。

角度差分测速现在使用：

```c
pos       /* 当前角度 */
fs        /* 采样频率 */
d_pos     /* 相邻周期角度差 */
pos_last  /* 上一周期角度 */
vel       /* 角速度 */
```

20 kHz 快速控制频率使用文件内常量 `FOC_FS_HZ`。它同时用于周期参数初始化和角度差分测速，避免同一个数字散落两处。

ADC 中断早于 `pmsm_init()` 启动，因此测速不能在启动初期依赖尚未初始化的运行时字段。本节点保留了原有编译期 20 kHz 行为。

## 代码规范整理

- 一行只保留一条语句。
- 修改区域统一使用 4 个空格，不使用制表符。
- 所有 `if` 分支补齐花括号。
- 每个 `switch` 都有 `default`。
- `case` 中的函数调用和 `break` 分行书写。
- 删除快速回调中已经失效的注释代码。
- 删除头文件中重复的快速停车和故障停车声明。
- 复杂函数使用简洁的中文 Doxygen 注释。

## 明确没有改变的内容

- 没有改变状态枚举和模式枚举的数值。
- 没有改变默认的 `debug_mode + curr_cl` 配置。
- 没有改变启动、复位、运行和故障处理顺序。
- 没有改变任一模式到原处理函数的映射。
- 没有改变控制周期计数器、轨迹状态或 PI/PID 公式。
- 没有改变 Clarke、Park、反 Park、SVM 和 PWM 提交顺序。
- 没有修改 display、VOFA 和调试结构体。
- 没有修改原始源码目录。
