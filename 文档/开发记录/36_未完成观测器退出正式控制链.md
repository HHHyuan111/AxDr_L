# 未完成观测器退出正式控制链

## 本节点做了什么

现有 `eh_observer.c` 的速度观测公式含有两个无法从当前资料确认含义的未初始化局部量。
该观测器的输出目前没有被状态机、控制环或 PWM 使用，因此本节点不猜测算法公式，
只将它从 CMake、Keil 正式固件源清单和快速反馈更新流程中移除。

## 改动边界

- 保留 `eh_observer.c` 源码，后续取得可靠公式后再单独完善和接入。
- 不修改 FOC、PI、SVPWM、状态机、采样和 PWM 时序。
- 不修改任何控制参数。

## 验收条件

- CMake 与 Keil 的项目自有源码清单保持一致。
- Host 测试全部通过。
- ARM GCC Debug、Release 全量构建通过。
- 正式快速链路不再调用未完成的 EH 观测器。
