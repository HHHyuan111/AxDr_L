# 母线电压除法确定性修复

## 本节点做了什么

`foc_feedback_update()` 需要用母线电压计算 SVPWM 的归一化系数。
当母线 ADC 原始计数为 0 时，换算后的母线电压也是 0，原代码会发生除零。

本节点按 ADC 的离散输入特性做最小修改：

- 原始计数大于 0：保持原公式 `1.5 / vbus`；
- 原始计数等于 0：归一化系数写为 `0.0f`。

## 改动边界

- 不改变任意非零 ADC 计数下的计算结果。
- 不增加新的保护阈值，不修改欠压参数和故障延时。
- 不修改 FOC、SVPWM、状态机和 PWM 的调用顺序。

## 验收条件

- Host 测试全部通过。
- ARM GCC Debug、Release 全量构建通过。
- `git diff --check` 通过。
