# 快速代码段跨编译器适配

## 本节点目标

把散落在 Control 和 Target 文件中的 GCC `section` 属性收口到一个项目级编译器适配头文件，
使算法文件不再直接绑定某一种编译器语法。

## 实现结果

- 新增 `User/common/compiler.h`；
- `PLATFORM_FAST_CODE` 统一表示需要放入 `.RamFunc` 的函数；
- `PLATFORM_FAST_DATA` 统一表示现有快速数据段属性；
- 旧代码中的 `_RAM_FUNC` 和 `_RAM_DATA` 暂时保留为兼容别名，避免无收益的批量修改；
- Control 与 Target 新模块不再各自定义 RAM 属性宏；
- CMake、Keil 和 Host 测试均加入 `User/common` 头文件路径。

## 验收结果

- 九组 Host 测试全部通过；
- CMake 与 Keil 用户源码清单一致；
- ARM GCC Debug、Release 全量构建均为 0 错误、10 个既有警告；
- 项目自有代码中的 `.RamFunc` 编译器语法只在 `compiler.h` 保留一处；
- 链接后的快速函数仍位于 RAM 地址区域。
