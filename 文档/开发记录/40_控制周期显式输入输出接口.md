# 控制周期显式输入输出接口

## 本节点目标

在不改变现有状态机和控制算法的前提下，为真实硬件、离线回放和 HIL 建立同一种
单周期输入输出数据合同。

## 接口说明

`control_cycle_input_t` 保存本周期控制器消费的物理反馈：

- 三相电流，单位 A；
- 母线电压，单位 V；
- 电角度、转子累计位置和输出轴累计位置，单位 rad；
- 快速周期序号。

`control_cycle_output_t` 保存本周期可以对外观察的结果：

- Drive 状态和故障位；
- PWM 软件使能状态；
- 逻辑 A/B/C 三相占空比及其有效性；
- 与输入一致的快速周期序号。

模式、给定值、控制参数和算法历史状态仍由 `pmsm_t` 上下文持有，不在每个周期重复复制。

## 当前硬件接入方式

```text
Target/现有采样换算
    -> control_cycle_input_t
    -> control_cycle_step()
    -> 反馈更新 + Drive
    -> control_cycle_output_t
```

当前固件仍由 Drive 在同一周期内提交 Target PWM，保持已有硬件动作顺序。本节点只建立
显式数据合同，不同时修改功率动作语义。电脑回放和 HIL 可以直接构造输入并使用 Fake Target。

## 验收结果

- 新增 Host 控制周期输入输出测试；
- 输入在反馈更新前完整写入控制器上下文；
- 反馈更新先于 Drive；
- 输出周期号、状态、故障和三相占空比均经过测试；
- 十组 Host 测试全部通过；
- ARM GCC Debug、Release 全量构建均为 0 错误、10 个既有警告；
- CMake 与 Keil 用户源码清单均为 39 个且完全一致。
