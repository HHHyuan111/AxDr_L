# 在用控制模式显式接口迁移

## 本节点目标

把当前实际使用的电压、电流、速度、位置 FOC 主链从 `pmsm_t` 内部操作顺序中抽出，
形成可在 MCU、电脑回放和 HIL 中共用的纯 C11 接口；同时抽出 MIT 给定计算，
不修改尚未确认的实验算法公式。

## 新的主链接口

`control_loop_step()` 使用四类显式对象：

- `control_loop_runtime_t`：PID 引用、三级分频状态和需要跨周期保存的控制量；
- `control_loop_feedback_t`：三相电流、电角度、母线归一化系数、速度和位置反馈；
- `control_loop_request_t`：控制模式和带单位的给定/限制；
- `control_loop_output_t`：FOC 中间量、级联输出和三相占空比。

支持的主链为：

```text
电压：FOC 反馈变换 -> d/q 电压 -> SVPWM
电流：FOC 反馈变换 -> d/q 电流 PI -> SVPWM
速度：FOC 反馈变换 -> 速度环 -> 电流环 -> SVPWM
位置：FOC 反馈变换 -> 位置环 -> 速度环 -> 电流环 -> SVPWM
```

原有 `foc_volt()`、`foc_curr()`、`foc_vel()` 和 `foc_pos()` 仍保留，当前只负责把
`pmsm_t` 映射到新接口并把结果写回，因此旧模式调用点无需一次性重写。

## MIT 处理

`control_mit_step()` 已把位置误差项、速度误差项和前馈转矩合成抽成纯算法。

当前旧代码虽然计算 `mit_tor_set`，但 q 轴电流参考仍只使用 `torm_set`。本节点明确保留
这一现有行为，没有把合成转矩擅自接入电流环。等 MIT 公式和预期行为确认后再单独修改并验收。

## 高级算法接入原则

参数辨识、观测器、自整定和无感算法暂不增加通用插件或函数指针框架。后续模块直接使用：

- `control_cycle_input_t` 提供的本周期物理反馈；
- `control_loop_feedback_t` 提供的 FOC/速度/位置反馈；
- `control_loop_output_t` 提供的控制量和占空比结果；
- 模块自己拥有的显式算法状态和参数。

只有取得可靠公式、状态复位条件和验收数据后，才把对应模块接入 Drive 模式分派。

## 验收结果

- 新增电压、电流、速度、位置与 MIT Host 测试；
- 四种 FOC 模式与迁移前固定执行顺序逐字段对照通过；
- PID 状态、三级分频状态、FOC 坐标结果和三相占空比保持一致；
- 十一组 Host 测试全部通过；
- Control 目录的 HAL、Target、寄存器和全局 `pm` 依赖均为 0；
- CMake 与 Keil 用户源码清单均为 41 个且完全一致；
- ARM GCC Debug、Release 全量构建均为 0 错误、10 个既有警告。
