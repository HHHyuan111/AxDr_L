# 开发记录 43：构建零警告门限

## 目标

把 ARM GCC 的 Debug、Release 构建从“允许 10 条历史警告”收紧为“0 条警告”，同时不修改 FOC 公式、
控制参数、采样时序或运行模式。

## 本次修改

1. 将 `bsp_fdcan.c` 和 `vofa.c` 从旧编码转换为 UTF-8，并明确标记当前未使用的回调参数。
2. USB 硬件初始化已经关闭 LPM，因此把 `USBD_LPM_ENABLED` 同步设为 `0U`，消除描述符配置不一致。
3. 在 CubeMX 用户代码区明确标记尚未使用的 USB CDC 参数。
4. `stm32g4xx_ll_adc.c` 在未启用 `USE_FULL_LL_DRIVER` 时是第三方空翻译单元，只对该文件关闭相应提示。
5. 快速周期函数按工程设计复制到 RAM 执行；针对 STM32G4 的该内存布局，仅关闭 GNU ld 的通用 RWX 提示。
6. 构建检查脚本的 Debug、Release 警告门限都收紧为 0。
7. 三个中文 PowerShell 验收脚本保存为带 BOM 的 UTF-8，兼容 Windows PowerShell 5 和 PowerShell 7。
