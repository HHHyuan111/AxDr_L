# 开发记录 44：Drive 安全输出闭环

## 目标

保证 Drive 每个 RUN 周期都只能使用本周期新生成、可提交的占空比；故障、非法模式、计算失败、
非法相序和非法占空比均不能继续沿用上一拍 PWM。

## 行为调整

1. START 先把三个 CCR 写成 50%，再打开三相输出，避免启动瞬间使用旧比较值。
2. 进入 `drive_fast_step()` 时先检查已锁存故障；存在故障时不再执行 START 或 RUN。
3. `drive_mode_step()` 返回本周期模式是否有效，未实现和未知模式明确返回失败。
4. RUN 周期结束前必须得到新的有效 `pwm_cmd`；没有新命令时立即停止 PWM 并清控制器历史。
5. `drive_pwm_commit()` 检查三相占空比是否为有限数且位于 0～1，并检查 ABC/ACB 相序。
6. 非法占空比或相序由 PWM 边界立即关闭 Target 输出，并保留最近一次有效提交记录用于诊断。

## 没有修改

- Clarke/Park、PI、SVM 和各控制模式公式；
- ADC、编码器和 TIM1 触发时序；
- 枚举数值和现有模式到实现函数的映射。

## 离线验收

| 检查项 | 结果 |
|---|---|
| Drive 状态测试 | 覆盖故障入口优先、启动顺序、无效模式、缺失本拍 PWM、停止和非法请求 |
| Drive 模式测试 | 覆盖已实现、未实现、未知模式及 FOC 失败返回值 |
| Drive PWM 测试 | 覆盖 ABC、ACB、非法相序、NaN、越界占空比和中性值 |
| Host C11 回归 | 11 组全部通过 |
| ARM GCC Debug/Release | 0 错误，0 警告 |

硬件上的输出关闭延迟、Gate/Break 独立关断和第一拍波形仍必须在上板阶段测量。
