# 反馈有效性闭环

## 本节点目标

把“硬件读取成功”和“本周期数据可用于控制”作为正式数据传进 Drive，避免通信失败后继续使用旧反馈。

## 实际改动

1. SPI 单字传输在发送、接收或总线忙等待超时后立即返回失败，不再继续读取无效数据。
2. MT6816 的两帧读取只有全部成功才更新原始角度；失败时保持上一次原始值并返回失败。
3. 快速周期显式传递电流、母线电压和位置三个有效标志。
4. 当前正式位置链只允许单 MT6816；未完成板级适配的其他编码器、双编码器和无传感器方案返回无效。
5. 电流或母线反馈首次无效即锁存故障；位置连续 3 个快速周期无效后锁存编码器故障。

## 保持不变的边界

- 没有修改 FOC、位置换算和保护阈值公式。
- 没有增加 SPI 重试、动态内存、日志或复杂恢复状态。
- ADC 原始读取仍沿用现有寄存器和 DMA 来源；其硬件同拍关系留待上电示波器验证。

## 离线验收

- 12 组 Host C11 测试全部通过。
- CMake 与 Keil 用户源文件均为 42 个，清单一致。
- ARM GCC Debug、Release 均为 0 错误、0 警告。

## 上电待验

- SPI1 两帧时序、片选间隔和 MT6816 返回数据正确性。
- 连续 3 次编码器通信失败时 PWM 是否按预期关闭并锁存编码器故障。
- ADC1 注入组、ADC2 注入组与 ADC2 DMA 数据是否满足控制周期的同步要求。
