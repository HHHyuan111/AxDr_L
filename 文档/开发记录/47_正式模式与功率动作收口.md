# 正式模式与功率动作收口

## 本节点目标

让状态机只启动已经接入当前硬件链和离线测试链的模式，并让发布命令、PWM 启停结果都有明确的成功或失败。

## 正式运行模式

当前允许进入 Drive 运行链的模式如下：

| 系统模式 | 允许的子模式 | 用途 |
|---|---|---|
| debug | drag_vf、drag_if、volt_op、curr_cl、spd_curr_cl、pos_spd_curr_cl | 分级上电调试和基础闭环 |
| release | cst、csv、csp | 周期同步转矩、速度和位置控制 |
| halt | quick | 有反馈的快速减速停车 |

以下源码继续保留，但不会启动 PWM：MIT、轮廓转矩/速度/位置、参数辨识、编码器标定、齿槽标定、故障减速模式、双编码器和无感观测器。原因是这些路径目前缺少完整的公式确认、硬件适配或数值验收。

## 命令适配

- 新增 `drive_cmd_apply()`，发布模式先校验命令、限幅范围和电机极性，再一次性更新内部给定。
- NaN、无穷、上下限颠倒或未知极性会拒绝本周期命令。
- START 之前也会执行同一校验，非法命令不会先启动一次中性 PWM。
- 命令失败时不发生部分字段更新。

## PWM 启停结果

- Target 将六路主/互补 PWM 的 HAL 启停结果返回给 Drive。
- 任一路启动失败会尝试关闭全部通道，并锁存 `pwm_err`。
- 停止时六路都要尝试；停止失败时保留 `pwm_active`，下一周期继续尝试停止。
- Drive 不再把“调用过 HAL”当成“硬件动作成功”。

## 默认启动配置

- 上电保持 STOP，默认模式为零给定的 `debug/curr_cl`。
- 位置反馈固定为当前已经接入的单 MT6816。
- 发布模式默认子模式改为已接入的 CSV。
- 未验证算法不再在上电初始化中运行。

## 离线验收

- 13 组 Host C11 测试全部通过，新增命令限幅、非法命令、未验证模式拒绝和 PWM 启停失败测试。
- CMake 与 Keil 用户源文件均为 43 个，清单一致。
- ARM GCC Debug、Release 均为 0 错误、0 警告。

## 上电待验

- 六路 HAL 启动和停止返回值与 TIM1 实际输出是否一致。
- 默认 `debug/curr_cl` 零给定启动时的三相波形。
- CST、CSV、CSP 的命令方向、限幅和机械侧/转子侧换算。
- 未验证模式下发送 START 时，所有三相输出保持关闭。
