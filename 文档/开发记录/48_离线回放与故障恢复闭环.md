# 离线回放与故障恢复闭环

## 本节点目标

验证连续控制周期的状态变化，并补齐可控的故障清除和控制器复位边界。

## 离线回放

新增一条不依赖 STM32 外设的连续回放测试，使用与固件相同的 `control_cycle_step()`、Drive、模式分派、保护、命令适配和 PWM 提交代码，只把 Target 换成电脑端假件。

回放顺序为：

```text
第 1 拍 STOP
  -> 第 2 拍 START，先写 50% 中性占空比并启动
  -> 第 3 拍 RUN，提交本周期三相控制占空比
  -> 第 4 拍位置反馈失效，锁存编码器故障并关闭 PWM
```

该测试验证模块衔接和状态时序；FOC、PID、级联环和 SVPWM 的数值正确性继续由现有逐拍对照测试验证。

## 故障清除

新增 `drive_fault_clear()`：

- PWM 仍活动时拒绝清除；
- PWM 已关闭时清除 Drive 故障位和保护锁存；
- 清除后回到 STOP，并复位控制器运行历史；
- 故障源仍存在时，下一次 START 会重新触发保护。

故障清除不会自行启动、停止或重配硬件。

## 控制器复位

新增独立 `drive_control_reset()`，替代原来放在算法模式文件中的复位函数：

- 清除四个 PID 的历史量，保留增益、周期和限幅；
- 清除三级控制环分频计数和内部给定；
- 清除上一拍 dq 电压和坐标变换输出；
- 把候选三相占空比恢复为 50%；
- 保留电机参数、保护配置、外部命令、当前位置和物理采样反馈。

## 离线验收

- 15 组 Host C11 测试全部通过。
- 新增 STOP-START-RUN-FAULT 连续回放、故障清除和控制复位测试。
- CMake 与 Keil 用户源文件均为 44 个，清单一致。
- ARM GCC Debug、Release 均为 0 错误、0 警告。
