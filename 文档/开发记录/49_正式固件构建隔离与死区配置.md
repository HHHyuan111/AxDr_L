# 开发记录 49：正式固件构建隔离与死区配置

## 1. 本节点目标

本节点只解决两个确定的问题：

1. 未经验证的实验算法不能进入正式固件镜像；
2. TIM1 互补 PWM 必须具有与板级参数一致的有效死区。

不删除旧算法源码，不修改 FOC、速度环、位置环和停机算法公式。

## 2. 正式固件源码收口

CMake 与 Keil 的用户源码清单由 44 个缩减为 28 个，并保持完全一致。

当前正式镜像只保留：

- App 快速周期、控制周期接口和调试快照；
- Drive 状态、模式、命令、保护、复位和 PWM 边界；
- 可移植 Control 数学与电压、电流、速度、位置控制主链；
- STM32G474 的 ADC、MT6816 和 TIM1 Target；
- 单 MT6816 位置反馈及当前已放行控制模式；
- 当前主程序仍使用的 LCD 显示代码。

以下源码仍留在仓库中，但不再编入正式固件：

- MIT、Profile Position/Velocity/Torque；
- 轨迹规划、参数辨识、标定、齿槽补偿；
- ALOB、NLOB、HFSI、SCVM、PLL 等无感或观测算法；
- 尚未接入正式边界的旧 CPU、FDCAN、Flash、GPIO、UART BSP；
- 旧 VOFA 实现。

Release ELF 符号检查未发现上述实验算法入口。代码段由 133456 字节降为
126960 字节，说明未验证实现不是“运行时不调用”，而是没有被链接进正式镜像。

## 3. 正式电机适配文件

原来混在实验文件中的在用功能整理为三个小文件：

| 文件 | 职责 |
|---|---|
| `encoder_feedback.c` | MT6816 参数初始化、原始计数读取和弧度换算 |
| `position_feedback.c` | 单编码器机械角、电角度和多圈位置更新 |
| `motor_modes.c` | 当前放行的开环、电流、速度、位置和快速停机模式适配 |

这次整理只移动当前确实使用的实现并改善注释，没有修改算法公式。

## 4. TIM1 死区

TIM1 时钟为 160 MHz，死区计数配置为 80。在当前时钟和 DTG 线性区间内：

```text
80 / 160 MHz = 0.5 us
```

`AxDr.ioc` 和 Cube 生成的 `tim.c` 已同步，避免以后重新生成工程时丢失配置。

这只是软件配置值。首次上电时仍必须在驱动输入或栅极波形上实测死区，确认通道极性、
驱动芯片内部死区和 MCU 死区叠加后的实际结果。

- 电流比例、母线比例、相序、编码器方向与零位需要在当前实物上校核。
