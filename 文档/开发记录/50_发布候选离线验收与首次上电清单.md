# 开发记录 50：发布候选离线验收与首次上电清单

## 1. 当前结论

代码已经达到“软件离线发布候选”状态：正式源文件边界已收口，15 组 Host 测试通过，
Debug/Release 零警告，CMake/Keil 清单一致。下一步不再凭感觉改算法，而是在实物上逐项确认
采样、角度、PWM 和故障关断时序。

仓库根目录执行：

```powershell
.\tools\verify_release_candidate.ps1
```

只有显示“发布候选离线验收全部通过”才进入上电步骤。

## 2. 上电前静态确认

- [ ] Git 位于本次发布候选提交，工作区没有不明修改；
- [ ] 电机参数、极对数、相序、编码器零位和电流/母线换算系数与当前实物一致；
- [ ] 默认 `pm.req` 为 `DRIVE_REQ_STOP`，`pm.pwm_active` 为 `false`；
- [ ] 确认所用驱动板是 FD6288 版本，并核对其输入极性和使能方式；
- [ ] 明确当前 TIM1 Break/Break2 没有外部故障源，不能把软件保护当作硬件逐周期过流保护；
- [ ] 使用限流电源、隔离测量和合适的急停/断电手段；第一次不要直接带负载运行。

## 3. 第一次：只上逻辑电，不启动三相输出

- [ ] 烧录后不写 START，确认状态长期保持 `STOP`；
- [ ] `fast_seq` 持续递增且频率符合 20 kHz；
- [ ] `pwm_active == false`，三相主/互补输出处于关闭状态；
- [ ] 手动转动电机，MT6816 原始值连续，`pos_valid` 为 true；
- [ ] 确认机械角方向、跨零累计圈数、电角度方向和电角零位；
- [ ] 三相电流原始值稳定在各自零偏附近，换算电流接近 0 A；
- [ ] 母线电压换算值与万用表一致；无母线时不要误判为可运行条件。

## 4. 第二次：只验证 PWM 和采样时序

- [ ] 保持功率级处于安全测试条件，先观察 TIM1 CH1/2/3 及互补通道；
- [ ] 确认中心对齐频率为 20 kHz；
- [ ] START 前无三相输出，START 时先得到约 50% 中性占空比；
- [ ] 实测上下桥臂有效死区，并记录实际值；软件目标值是 0.5 us；
- [ ] 确认 A/B/C 相序映射和高低有效极性；
- [ ] 同时观察 TIM1 CH4、ADC 采样点和 PWM 更新点，确认采样位于期望的低噪声窗口；
- [ ] 测量一次 MT6816 读取和完整快速中断的最坏耗时，确保小于 50 us 且有余量。

## 5. 第三次：受限功率试运行

- [ ] 先使用零电流闭环，给定值保持 0，确认没有异常电流和转矩；
- [ ] 从很小的 q 轴电流开始，确认电流方向、相序和编码器方向形成负反馈；
- [ ] 依次验证 STOP、START、RUN、STOP，不跨级直接测试位置环；
- [ ] 电流环稳定后再验证低速速度环，最后才验证小范围位置环；
- [ ] 每一步保存母线、电流、角度、状态、故障和三相占空比快照；
- [ ] 任何方向错误、振荡、过流或角度跳变立即退回 STOP 并断电排查。

## 6. 故障链验证

- [ ] 在安全条件下制造编码器读取无效，确认连续 3 个无效样本后锁存编码器故障并关闭 PWM；
- [ ] 验证欠压、过压和过流软件阈值及锁存行为；
- [ ] 实测从故障出现到栅极关闭的总延迟，不能只看软件状态变化；
- [ ] PWM 未关闭时 `drive_fault_clear()` 必须失败；输出关闭后才能清故障并重新 START；
- [ ] 在确定硬件故障信号来源和极性后，再单独设计并验证 TIM1 Break 硬件关断；
- [ ] 温度 ADC 接入前，不把 MOS/绕组温度保护列为已通过项目。
