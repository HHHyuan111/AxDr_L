# FOC 核心算法统一接口

## 本节点做了什么

本节点把原来的四种 FOC 控制链收口为 `foc_ctrl_step()`，并确定核心算法层使用的四类对象：

| 对象 | 大白话含义 | 保存内容 |
|---|---|---|
| `foc_ctrl_t` | 控制器本体 | 三闭环分频状态、PI 引用和跨周期控制量 |
| `foc_fb_t` | 这一拍实际测到了什么 | 三相电流、电角度、速度、位置和母线调制系数 |
| `foc_ref_t` | 这一拍想让电机做什么 | 模式、给定值和限制值 |
| `foc_out_t` | 这一拍算出了什么 | 坐标变换结果、级联参考和三相 PWM 占空比 |

调用关系现在可以直接读成：

```text
反馈 fb + 给定 ref
        ↓
foc_ctrl_step(ctrl, fb, ref, out)
        ↓
电流/速度/位置级联 + FOC + SVPWM
        ↓
结果 out
```

核心接口不包含 STM32 HAL、ADC 寄存器、PWM 定时器和全局 `pm`。以后切换板卡时，
只需要适配层给它准备相同格式的 `fb`，再把 `out.pwm` 交给新板卡，不需要修改这套控制算法。

## 本节点没有改什么

- 没有修改 Clarke、Park、逆 Park 和 SVPWM 公式；
- 没有修改电流环、速度环和位置环公式；
- 没有修改任何 PI 参数；
- 没有修改 ADC 触发、编码器采样和 PWM 提交时序；
- 没有接入新的运行模式。

这次是接口重组，不是控制效果调参。

## 命名约定

本节点按已确认的简洁命名执行：`foc`、`ctrl`、`fb`、`ref`、`out`、`cur`、`spd`、
`pos`、`pwm`。缩写字段的物理单位统一写在结构体接口注释中，避免名字过长，同时保留含义。

## 验证结果

- 四种模式均通过主机测试；
- 新旧算法的坐标变换、占空比、四个 PI 状态和三级分频状态逐位一致；
- 全部 19 组主机测试通过；
- 正式代码规范检查通过；
- CMake 和 Keil 均为 43 个正式用户源文件，清单一致；
- Debug 和 Release 均为 0 错误、0 警告。
