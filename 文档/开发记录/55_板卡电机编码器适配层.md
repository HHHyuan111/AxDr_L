# 板卡、电机与编码器适配层

## 为什么要增加这一层

Target 只知道“ADC 读到了 2100”“编码器返回了 5000”，FOC Core 只应该接收
“A 相电流是多少安培”“转子角度是多少弧度”。两者中间必须有一个地方解释：

- 哪条物理采样链对应电机 A/B/C 相；
- ADC 零偏是多少；
- 一个 ADC count 等于多少安培或多少伏特；
- 当前使用 MA732 还是 MT6816；
- 编码器一圈多少 count，方向和零位怎样定义。

这个解释层就是 Adapter。

## 现在的目录职责

```text
User/config
  board_config.h       当前驱动板电路和保护参数
  motor_config.h       PR60/2312S 电机物理参数、相序和零位
  encoder_config.h     编码器型号、方向和分辨率

User/adapter
  board_adapter.c      ADC 相序、零偏、电流和母线电压换算
  encoder_adapter.c    MA732/MT6816 原始读取和单圈角换算
  position_adapter.c   单圈角到电角度、多圈位置和输出轴位置
```

算法参数仍放在 `User/control/algorithm_config.h`，没有和硬件参数重新混在一起。

## 一拍采样现在怎么走

```text
target_adc_read_raw()
        ↓  板上原始 count
board_adc_convert()
        ↓  相序映射、扣零偏、乘换算比例
i_a / i_b / i_c（A）和 v_bus（V）
        ↓
fast_loop -> FOC Core
```

这次没有修改任何换算公式，只把原来散在 `foc_drv.c` 和 `fast_loop.c` 的步骤集中到了
`board_adapter.c`。ABC、ACB 两种映射及非法相序都有独立主机测试。

## 以后怎样迁移

- 换电机：选择或新增 `motor_config.h` 中的电机参数；
- 换采样电路：修改 `board_config.h` 的电阻、增益和保护阈值；
- MA732 换 MT6816：修改 `ENCODER_SELECTED_TYPE`；
- 换 MCU：重写 `target_adc/target_encoder/target_pwm/target_irq`，Adapter 和 Core 保持不动。

## 本节点不做的事

现有正式运行仍由历史 `pmsm_t pm` 承载。把它整理成最终的 `foc_t g_foc` 属于下一个节点，
本节点先保证硬件数据边界和配置归属清楚，避免同时大改数据结构和底层换算。

## 验收条件

- 板卡原始数据换算有独立主机测试；
- 电机、驱动板、编码器和算法参数分属四个清晰配置文件；
- Adapter 不直接访问 STM32 HAL 或寄存器；
- FOC Core 不依赖 Adapter 或 Target；
- 全部主机测试、代码规范、CMake/Keil 清单及 Debug/Release 构建通过。
