# 正式代码收口与周期记录

## 本节点目标

把架构重构后的正式代码入口收干净，同时给后续上电波形检查和离线回放提供一个很小、默认关闭的数据记录口。这个节点不改 FOC 公式、不重写 HAL，也不增加通信协议。

## 本次完成内容

### 1. 正式 Motor 目录收口

`User/motor` 现在只保留当前正式链需要的文件：

- `common.h`：正式 FOC 数据类型和当前入口；
- `foc_fwd.h`：`foc_t` 前向声明；
- `foc_drv.c`：配置装载、反馈更新和 FOC 薄适配；
- `motor_modes.c`：正式运行模式到 Control 的适配。

旧辨识、旧轨迹、旧无感和旧编码器组合移到 `reference/legacy_motor`，仍可查阅，但不进入 CMake/Keil 固件。旧查表三角函数只保留在 `tests/legacy/legacy_trig.c`，用于新旧数值对照。

### 2. FOC 总对象减负

`common.h` 删除了没有进入正式控制链的旧辨识、旧无感、旧标定、旧轨迹和重复滤波器状态。正式对象只保留：

- 板卡、电机、编码器配置；
- 当前 ADC 和控制反馈；
- Drive 请求、状态、故障、保护和 PWM 记录；
- 四个控制器、两个实际使用的滤波器；
- MIT、速度轨迹和位置轨迹状态。

正式命令字段收口为 `g_foc.cmd.torq/spd/pos/mit_ff/kp/kd`，主编码器摘要收口为 `g_foc.enc.raw/pos`。

### 3. 新增轻量周期记录器

新增 `cycle_record.c/.h`。它具有以下边界：

- 上电默认关闭；
- 打开后记录最近 32 个快速控制周期；
- 固定内存，不动态申请；
- 记录状态、模式、故障、三相电流、角度、位置、速度、`d/q` 电流、`d/q` 电压和占空比；
- 写满后覆盖最旧数据；
- 只记录，不参与任何控制判断。

使用方法：

```c
cycle_record_enable(true);   /* 清空并开始记录 */
cycle_record_enable(false);  /* 停止记录 */
```

调试器中直接观察 `g_cycle_record`。
