# 实时控制变量极简命名

## 本次目标

把快速控制主链中重复单位、含义绕口的字段统一成电机控制常用短名，让代码和调试器窗口能够直接阅读；本次只改名称，不改变算法、执行顺序和数据流。

## 命名规则

- ADC 原始计数统一放在 `raw` 下，例如 `g_foc.adc.raw.ia`。
- 换算后的实时物理量直接使用 `ia/ib/ic`、`vbus`、`theta_e`、`pos_r`、`spd_r`。
- 坐标变换量使用 `ialpha/ibeta`、`id/iq`、`valpha/vbeta`、`vd/vq`。
- 三相占空比保留可读的 `duty_a/duty_b/duty_c`，不缩成难懂的单字母。
- 实时结构体的单位统一写在类型注释中：电流 A、电压 V、角度和位置 rad、速度 rad/s。
- 电机参数、保护阈值和算法配置仍保留 `_a`、`_v`、`_rad_s` 等单位后缀，避免换电机和调参时填错单位。

## 主链对应关系

| 数据阶段 | 当前写法 | 含义 |
|---|---|---|
| Target 原始采样 | `target_adc_raw_t raw` | 尚未换算的 ADC 计数 |
| FOC 内保留的原始值 | `g_foc.adc.raw.ia` | A 相电流 ADC 原始计数 |
| 板卡适配结果 | `sample.ia` | 已扣零偏并换算为 A 的 A 相电流 |
| 周期输入 | `input.ia` | 当前快速周期送入控制链的 A 相电流 |
| FOC 实际反馈 | `g_foc.sig.ia` | Clarke 变换真正读取的 A 相电流 |
| dq 电流 | `g_foc.sig.id/iq` | Park 变换后的电流反馈 |
| dq 电压 | `g_foc.sig.vd/vq` | 电流环或电压模式产生的电压命令 |
| PWM 候选值 | `g_foc.sig.duty_a/b/c` | FOC 计算出的逻辑三相占空比 |
| PWM 正式命令 | `g_foc.pwm_cmd.duty_a/b/c` | Drive 检查后交给 Target 的命令 |

## 解耦关系

这些名字相同不代表数据耦合。每层仍通过自己的结构体传递：Target 只提供原始计数，Board Adapter 只负责相序和物理量换算，App 组装一拍输入，Control 只做数学计算，Drive 决定是否允许输出，Target 最后写定时器。`debug_snapshot_t` 只是从 `g_foc` 复制只读镜像，修改它不会反向改变控制变量。

## 验证结果

- 正式代码规范检查：121 个 C/H 文件通过。
- Host：23 组测试通过，覆盖 FOC、三级闭环、状态机、保护、适配层、扫频和参数辨识。
- CMake 与 Keil：48/48 个 User 源文件一致。
- Keil Debug：0 error、0 warning。
- Keil Release：0 error、0 warning。

上述结果证明本次改名没有改变现有离线可验证行为；实机采样时序、相序和功率输出仍需按上电清单逐层确认。
