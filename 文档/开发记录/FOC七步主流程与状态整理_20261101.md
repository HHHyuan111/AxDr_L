## 状态与兼容

| 本拍运行状态 | 进入条件/行为 | 对上位机的原状态 |
|---|---|---|
| IDLE | STOP、非法请求、未启动的 RUN；关闭输出 | STOP=0 |
| STARTUP | 模式和保护允许启动，已对齐或绝对编码器；中性占空比后开启，下一拍运行 | STARTING=1 |
| ALIGN | ABZ 尚未对齐；生成对齐电流和场角 | STARTING=1 |
| CONTROL | 已启动的普通控制；按 VF/IF/电流/速度/位置等模式生成给定 | RUN=2 |
| DIAGNOSTIC | 已启动的已支持诊断；诊断给定和电压边界单独检查 | RUN=2 |
| FAULT | 故障锁存或本拍动作失败置故障；关断并要求显式清故障 | FAULT=3 |

状态由本拍锁存的请求和硬件软件状态选择，保存在栈上的 `drive_cycle_t`；跨拍的请求、对齐进度仍存 `foc`，不新增第二份跨拍状态。最终结果映射到旧 `foc->state`。对齐成功仍主动停机，下次显式 START 才能运行。快速减速完成发 STOP，保持原下一拍关闭语义。

启动写 50% 后开启输出是进入状态的必要动作；故障停止不受普通占空比提交限制。正常占空比集中在 `drive_output` 提交。对齐收尾仍在本拍输出后完成。对齐计算无效时改为停止，避免保持旧占空比继续累积对齐进度；这是本轮明确的保护收紧，需要离线失败注入覆盖。

## 验收

1. 主流程单屏可见七步，ADC 回调不组装控制输入；显式离线输入与硬件输入共用同一控制流程。
2. 新旧模式给定、连续 PI/分频/角度/占空比结果对照；启动先中性再开启，对齐成功回 STOP，故障、无效占空比同拍停止。
3. 有效与无效采样、模式拒绝、诊断限幅、ABZ 对齐、控制数值、上位机状态兼容检查通过；ARM 编译链接和栈/RAM 检查完成。

## 未验证、风险和下一步

本轮没有烧录、真实 ADC/PWM 测量、电机运动或上位机联调。20 kHz 时限、ISR 嵌套栈峰值和输出引脚关断延迟仍需上机确认。ABZ 对齐的圆均值集中度只验证角度集中，不能独立证明转子跟场到位，原算法参数没有改变。

本轮不宣称整份固件已解除所有耦合：`foc_drv.c` 仍兼有初始化和运行适配，部分 Adapter 仍接收 `foc_t`，服务命令的多字段原子性、测速启动/丢样恢复边界留待单独任务。已有磁链观测仍未接管控制角度，不是完整无感闭环。

负责人先阅读 `control_cycle.c` 的七步与 `drive.c` 的状态选择；若表达和编排可读，再按项目规则冻结本候选并先做板端状态预检，之后验收启动、对齐、已验速度模式和停机。本轮不直接进入新算法开发，也不把离线通过称为实机闭环。
