## 问题、依据与一个假设

现有 20 kHz 短录波仅 1024 点，时长 51.2 ms。四路 float32 一秒需要 320,000 B，不能放进本机型 128 KiB RAM。AXSF v1 固定 212 B，每包五点，20 kHz 需要 4000 包/s，即 848,000 B/s；现有两包 424 B 合发仍需要约 2000 次提交/s。

本轮唯一假设：保持同拍取样、AXSF v1 和非阻塞队列，仅在 20 kHz 档最多四包合发（848 B），可以降低提交频次；电脑独立有界记录器可以完整接收一秒数据。四包是上限，队列不足时不等待凑包，因此不保证实际提交频次一定为 1000/s。USB 实际吞吐、控制中断余量尚未验证；不以 USB 标称速率或离线生成数据证明实机通过。32 包环保持，20 kHz 仅约 8 ms 容量，长停顿仍可能溢出，必须报告。

依据：当前 service_observation.c、service_usb_tx.c、usbd_cdc_if.c、ST USB CDC 多包完成回调及协议契约。低速档继续最多两包；20 kHz 新增 bit26 能力表示支持请求，不代表性能已验。固件候选 0.7.8 / 0x20261028。不改采样/FOC/保护算法，不改现有 1024 点短窗，不增 RTT。

## 实机结果、恢复与下一停点

负责人已许可刷写并回复“已停机关闭”。COM3 身份为普通版，UID `0037002F 3741500A 20383859`，J-Link S/N 174504220，VTref 3.285～3.308 V。芯片读出 512 KiB、DBANK=1；CCER=0x1000、BDTR=0x0200A050，三相关闭而 MOE=1。`target_pwm_stop_phase_outputs()` 关闭 CH1/2/3 和互补输出；`target_adc_start()` 保留 CH4，不能宣称 MOE=0。Safety 输出关闭位与 Control STOP 一致。

试验前完整 Flash SHA256 为 `042ADFC3F5B3691A7DEFF5F4D64B7C626190C9FE1E230FC2FF92BCBA34B5E8A6`。候选只影响 0x08000000～0x08020FFF 的程序页，读回与 BIN 一致，程序页以外和 0x08040000/0x08040800 参数页均与原备份相同。未整片擦除，未写选项字节。

前置工具问题与真实采集失败分开：

1. 首次只读预检被工具 36B 固定长度拒绝。实际当前源码和报文都是 44B，尾部追加首故障字段；修正为严格接受 36/44B 并拒绝首故障非零，其他长度仍拒绝。旧工具 73 项及新增对应检查通过，无板端源码修改。
2. `capture` 目录只运行了采集关闭时的基线，尚未发启流命令。IRQ 计数两次均 4220，但慢遥测控制 tick 持续增长。SEGGER 文档明确调试退出默认清理周期计数器；改用 `SetRestartOnClose=1`、`SetSkipDebugDeInit=1` 后复位同一镜像，下一次一秒基线 IRQ 增长 20,000，新增异常均零。此项是测量条件恢复，不能把原失败日志改成通过。连接动作自身可能重新使能 DWT，因此重连读寄存器不能单独证明退出前状态；归因依据为源码条件、官方说明和修正后的串口计数证据。
3. `capture-counter-preserved` 中仅一次启流。合格前缀为序号 1～77、每路 385 点；第 78 包首次报告 dropped_samples=10。原始 RX 共收到 89 包/每路 445 点，所有 CRC 正常、原始值有限；末包累计丢样 30，停止后诊断累计丢样 45、产生点数 650。剩余排队样本在停止时丢弃，不能把 650−445 全部计为传输丢样。数据未达到每路 20,000 点，实测拒绝。
4. 采集前基线 IRQ 最大耗时 3052 cycles，试验后高水位 3781 cycles，在 160 MHz 下分别约 19.075/23.631 μs；新增 IRQ 超期、IRQ 间隔缺口、ADC overrun、TX 错误均零。最大命令应答 1.8863 ms。只限停机短窗口，不证明电机运行时的控制余量或长时间吞吐。
5. 停止应答成功、stream_id=0、queued_packets=0，随后 Safety/Control 均停机正常。原 `result.json` 把之后的丢样统计异常错误归类为 stop_confirmed=false；原文件保留，通过原始 ACK 重放生成 `capture-review.json` 纠正分类，数据仍为失败。工具现将“停止确认”和“数据质量”分别记录，保留首个失败原因，并在基线失败时保存原始诊断；14 项离线检查通过，没有再跑硬件采集。
