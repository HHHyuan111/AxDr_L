# 固件资源模块开发记录

日期：2026-11-01。基线：2f3c147。状态：固件侧实施完成、离线验证通过；AfterMake 产包未接通（等上位机身份核对）。

## 六项对齐决策（负责人确认）

1. 版本统一 0.7.9（唯一来源 axdr_build_id.h，构建脚本生成）；
2. 0x2B payload 固定偏移 80B（packed 结构 + 2B reserved）；
3. stats_seq 独立于 irq_count（每次查询自增的应答序号）；
4. boot_id 用 Bank2 第 3 页（0x08041000）追加记录 + CRC，页满才整页擦除（≈256 次上电擦 1 次）；
5. build_id 由构建前脚本一次生成，贯穿固件/回执/资源包；
6. 产包先输出 build_identity.json / build-result.json / frozen MAP-AXF-BIN，AfterMake 待接通。
