## 3. 状态机现在怎样读

先读 `app/control_cycle.c` 的七步，再读 `drive/drive.c` 的 `drive_update_state`。后者明确回答“现在是什么状态、什么条件下离开”。`drive_enter_state` 集中做启动或关断动作，`drive_handle_state` 生成本拍给定。

```text
STOP（停止）──显式 START──> STARTING（启动一次）──下一拍──> RUN（运行）
                              │                         或 DIAG（诊断）
                              └──ABZ 尚未定零──> ALIGN（对齐）──完成──> STOP

运行中收到 STOP：关断后回 STOP
任意状态发生故障：关断并保持 FAULT；显式清故障后回 STOP
```

唯一跨拍运行状态是 `foc->state`。`req` 只是外部请求，`drive_cycle_t` 只放本拍给定和计算是否有效，已经删除另一套临时运行枚举及输出末尾的状态反向映射。

重复 START 不重置 PI、不重开 PWM，也不跳过本拍控制。STOP 状态不接受单独 RUN 绕过启动。对齐完成后仍需再次显式启动；普通运行与诊断之间需要先停机。关断失败保留 `pwm_active` 和 FAULT，下一拍重试；不会因为清掉故障位就自动离开 FAULT。

旧状态值 0～3 保留，内部追加 ALIGN=4、DIAG=5。`service_drive_state.h` 在运行查询和遥测两处把 ALIGN/DIAG 转换为旧协议的 STARTING/RUN，协议长度和编号没有变化。调试快照、周期记录和离线输出保留真实内部状态，使用它们的脚本需认识 4/5。被动观测分别检查中性启动、对齐和诊断的数据有效性。

## 4. 命令更新怎样避免半组给定

现象：主循环先写模式、再写目标，ADC 中断可能在两次赋值之间进入，看到新模式与旧目标。

动作：复用现有 BSP `target_irq_lock.h`，保存 PRIMASK 后屏蔽中断，写完整组模式/目标/请求，再恢复原屏蔽值。数值校验、协议解析、回复、CRC 都在临界区之外。取得临界区后再次检查故障，避免校验后新发生的故障仍被启动命令覆盖。保持既有同步应答合同，没有引入异步邮箱。

电流 PI 的停止条件检查和系数写入也在同一短临界区；即使状态暂为 STOP，只要 START 已排入或 PWM 仍活动，就拒绝修改。恢复默认 PI 仍调用原公式，没有新增第二份参数计算。

检查：在临时源码副本的每次模式/目标/请求赋值之后尝试控制抢占。旧实现记录 10 次混合读取；新实现 0 次，33 次写入期间抢占被屏蔽。生产源码没有插桩。另检查了嵌套屏蔽值恢复、发布后 STOP 保留、发布前新故障拒绝，以及待启动时 PI 修改/恢复拒绝。关中断的真实时长尚未实测。

证据：`command-preemption.json`、`command-baseline.log`、`command-candidate.log` 及 `host-tests/test_service_command.log`。插桩对照先于最后补充的 PI 门禁用例，后者单独定向通过；不把主机插桩描述为 MCU 抢占实测。

## 5. 测速修正怎样检查

原问题有两处：N 拍差分只收 N 个样本就开始计算，使用了尚未填入的历史零值；无效位置被调用方跳过，恢复时仍按 N 个周期计算，缩短了实际时间。

现在 N 拍差分要求 N+1 个连续有效样本。无效位置、非有限值或序号不连续都会重建窗口，期间保留上次速度。序号采用无符号差，正常回绕仍视为连续。历史移到各电机自己的 `foc->speed`，重置一个电机不影响另一个。

| 同一输入的主机对照 | 旧实现 | 新实现 | 通过标准 |
|---|---:|---:|---|
| 位置固定 1 rad，20 kHz，第二拍 | 10000 rad/s | 0 rad/s | 静止不产生速度 |
| 连续 20 rad/s，缺一拍后恢复 | 30.000210 rad/s | 19.999743 rad/s | 恢复不产生压缩时间造成的尖峰 |

`test_speed_adapter` 还覆盖两个电机交错输入、角度跨零、序号回绕、缺调用、NaN、无效频率及重新初始化。正常窗口公式和低通参数保持。窗口内转角小于 pi 的原解卷绕适用条件仍在；重建期间保持旧速度不是新测量值，位置有效性继续参与保护。

证据：`speed-regression.json` 和 `host-tests/test_speed_adapter.log`。
