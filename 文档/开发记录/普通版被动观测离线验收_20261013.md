# 普通版被动观测离线验收

本轮建立可靠的被动观测通道，未调整 PI、PWM/ADC 配置、死区补偿、保护或运动算法。停机实板结果见文末；沙沙声根因和采集对运行控制时序的影响尚未验收。

## 范围与版本

从普通固件 `dev/c25aadf` 及既有两处电流 PI 工作树修改开始，原修改保留在 `axdr_command_contract.h`、`service_command.c`，不纳入本轮提交。因此本机候选由“本轮提交 + 已冻结的既有修改”构成，不能仅凭 Git 提交复现全部字节。冻结证据位于 `D:/host compuer/.codex-tmp/verification-20261013/baseline-inputs.zip` 和 `freeze.json`。

新协议身份为 `AxDrService 0.7.7 / 0x20261013`，能力位 25，命令 `0x30～0x36`；不借用旧 `0x1B～0x1F` 主动扫频协议。普通上位机位于 `D:/host compuer`，对拖和沉沙工程未修改。

USB 统一复制入有界发送队列，最终 CDC 完成回调后释放，命令优先，BUSY 时不忙等。主循环每轮最多消费 256 B 接收数据。实时观测默认关闭，最多四路，500/1000 Hz；短窗为 20 kHz、1024 点、四路原始 float32，最多 16 KiB。中断只采样和入队，CRC、传输及读出在主循环执行。无效信号保留 NaN，真实时序缺口独立标记。

主要文件为 `service_usb_tx.c/.h`、`service_usb.c/.h`、`service_observation.c/.h`、`axdr_observation_contract.h`、`target_irq.c`、`target_irq_profile.h` 及装配入口、构建清单、对应 Host 测试。

## 实机停点

本轮只读检查回报普通 0.7.6，Safety 失能、无故障、无运行授权，Control STOP；J-Link VTref 3.336 V，UID `0037002F 3741500A 20383859`，TIM1 CCER `0x1000`（仅 CH4，三相输出关闭），BDTR `0x0200A050`。2 秒旧遥测探针有 40 个有效帧、11 次 CRC 错误、序号缺口 0、末帧母线 24.79 V，通信完整性未通过。

随后只读备份 512 KiB Flash 成功，SHA256 `C3D656F4CC8B24E08798B9CF0F9E9A3F4CCD7F3A851D5E30A6F7657E2A9596A1`。两次检查之间 CPU 由运行变为暂停（PC `0x0800231C`），当时有多个 Keil 窗口，原因待确认；未发 halt、reset、下载、使能或运动命令。硬件操作在此停下，等待调试占用来源明确。证据在 `D:/host compuer/.codex-tmp/observation-20261013/`。

后续先恢复独占且干净的停止状态，再按单一候选下载、独立读回及参数页核对。通过后分开验证关流基线、四路 1 kHz、20 kHz 短窗，检查 CRC、缺样、IRQ 超期增量和命令响应。完整中断测量不含异常入栈/退栈及 profiler 收尾，必须保留余量；静态 RAM 和离线构建不代表实时预算已通过。联合实机验收前不推送或发布。

## 后续停机实板验收

用户回复“结束了，你来吧”后，复位旧固件并重复五项只读状态检查，确认普通 0.7.6、STOP、失能、故障/目标 0。复位暂停时确认 TIM1 CCER/BDTR 和 DMA 通道均为 0，才下载上述唯一候选。独立重新连接、禁用缓存，读回 512 KiB：前 133000 B 与候选零差异，`0x08020800` 之后全部保持，两页参数保持。复位后身份为 0.7.7 / 0x20261013，STOP、失能、故障 0。

新增 `tools/verify_passive_observation.py`，默认只离线自检，硬件须显式 `--run`。白名单仅允许 GET `0x01/02/03/08/0C` 及观测 `0x30～0x36`；不发送 ARM、对齐、目标、STOP 或心跳。身份与停止门通过后逐阶段验收，失败也尝试取消、关流并复核停止。68 项离线自检通过，包含完整模拟流程及真实 C 帧解码。

本次 `--phase all` 在 `artifacts/verification-20261013/passive-board-01/` 留存原始 RX/TX、CSV、float32 和 JSON，结果 PASSED：

- 关流基线 1 s，IRQ 计数增加 20000，无异常增量。
- Ia/Ib/Ic/Vbus 四路 1 kHz，5 s 收到 1001 包、5005 点，无 CRC/帧头错误、序号/时间缺口、丢点、非有限值。
- 20 kHz 短窗 1024 点、四路 16384 B，完整分块读回，数据和状态冻结，无缺样。
- 关流中断高水位 3072 周期（19.20 μs）；采集期间高水位 3816 周期（23.85 μs），核心 160 MHz。ADC 异常、IRQ 超期/间隔异常、发送错误均无增量。
- 185 次应答最大 1.047 ms，发送队列峰值 3。结束 stream_id=0、队列 0、Safety 失能、Control STOP、目标/故障 0。

新固件同类慢遥测探针为 52 个有效帧、CRC/序号缺口 0，旧镜像探针曾有 11 次 CRC 错误。以上只证明本轮短时停机观测；运行控制耗时、栈高水位、长时通信、断连与沙沙声仍未验收。未发使能、对齐或运动指令，未改控制参数，未上传 Git。
