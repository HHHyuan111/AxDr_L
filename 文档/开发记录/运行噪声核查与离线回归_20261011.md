# 运行噪声核查与离线回归

## 当前结论

电机正常旋转但有沙沙声，根因未确认。当前没有 J-Link USB 枚举，用户已要求先做离线优化。本轮不烧录、不复位、不使能、不试转、不修改生产控制算法。
普通固件基线为 `dev/04b1c51`；用户的 `service_command.c` 与 `axdr_command_contract.h` 电流 PI 协议修改保留，不纳入本节点提交。
本任务无独立 SDD。授权与范围见 `D:/host compuer/docs/agent/任务卡_全览与运行噪声核查_20261011.md`，不修改本聊天目录 3.8.x 工程或对拖工作树。

## 已确定的源码事实

| 观察对象 | 当前源码 | 结论边界 |
|---|---|---|
| PWM / 死区 | 160 MHz、中心对齐 ARR 4000、DTG 80 | 约 20 kHz / 0.5 μs；栅极实际死区未测 |
| 三相 ADC | ADC1 三 rank、47.5 周期采样、12.5 周期转换、40 MHz | 理想序列约 4.5 μs，三相不同刻；触发延迟与采样稳定窗口仍需实测 |
| 快环触发 | 只接受 ADC1 且 JEOS 置位 | 已有序列完成门槛；本节点补离线回归，不把其存在当本次声音已修复 |
| 电流 PI | `Kp=Ls*ibw`、`Ki=Rs*ibw` | 不盲调带宽，先确认 Rs/L 和电流量测；历史参数不是当前板端回读 |
| 死区补偿 | 已有连续过零及占空比限幅路径，默认关闭 | 极性、幅值与降噪效果未在本板验证 |
| 高频数据入口 | 固件 `service_scope` 将 0x1B～0x1F 改作扫频；宿主仍有旧抓波契约 | 不能直接调用旧抓波命令；先核对镜像/版本/能力和 payload |
| 周期记录器 | 默认关闭、32 点 | 20 kHz 下约 1.6 ms，不足以直接判断低速六倍电频谐波 |

只读历史证据在 `artifacts/preflight-20261011`：COM3 60 帧约 24.9 V、STOP、故障 0、CRC/帧头错误 0。占空比 0.5 不等于 PWM/MOE 已关闭；这些数据不是新的实机验收。

## 本节点修改和检查

测试现象：完整脚本不能编译 ADC 句柄门槛；方向保护测试把前四个正常 RUN 动作累加到停机断言；诊断适配测试缺新服务头搜索路径；用户 PI 协议新增 `cur_pi_init` 依赖使两个服务测试不能链接。
假设：测试入口与已存在生产接口脱节，不需更改算法。
实验：仅修宿主测试替身、逐周期断言、头搜索路径和未覆盖 PI 路径的失败替身，再执行严格 C11 全套测试。
通过标准：ADC 空句柄、其他 ADC、未完成序列均不执行快环；ADC1 JEOS 执行一次；1 kHz 下反向保护第五个样本关输出并锁故障；非法补偿配置逐位等同关闭路径。

`tools/run_host_tests.ps1` 退出 0，37 条 Host C11 检查通过，包含控制链、保护、USB 安全链、扫频与诊断算法。原始日志：`artifacts/preflight-20261011/host-tests.log`。
数学测试补极性翻转、关闭路径和七种非法配置；未覆盖的电流 PI 恢复若进入替身即报失败，不能把全套通过解释为用户新 PI 协议已验收。
生产 C/H、时钟、ADC/PWM 配置与控制参数均未改变，因此本节点不新增板端 RAM/FLASH 开销；本轮没有新建或烧录固件镜像。

## 资料复核与下一次唯一实验

[Microchip MCAF 死区说明](https://microchiptech.github.io/mcaf-doc/7.0.2/algorithms/dead-time-comp.html)：dq 死区失真可随电角度每周期重复六次；过零区不能当成固定 sign，参数需实测。每相平均误差主要项约 `Vdc*tdead/Tpwm`，24.9 V、0.5 μs、50 μs 对应约 0.249 V，不能把线间系数直接套作每相值。
[VESC 开源 FOC](https://github.com/vedderb/bldc/blob/master/motor/mcpwm_foc.c) 的 `update_valpha_vbeta` 用滤波后的 dq 电流重构相电流，修正电压估计。它并不直接证明本项目 SVM 后 duty 补偿的极性正确；MCU、功率级、测量极性及用途均不同，不复制其参数或实现。

下次假设：噪声中的主要电流纹波与六倍电频同步，而非随机采样污染。
先恢复 J-Link，冻结源码、完整 Flash 与参数页回退证据，检查 VTref、USB 身份、Safety/Control、故障、PWM/MOE。状态不干净停止本实验。
仅采集当前关闭补偿基线，不同时改 PI、触发、PWM 或补偿。先核对高频观测入口；普通约 20 Hz 遥测不用于高频频谱判断。
采集率须足以分辨目标频段，记录时长至少覆盖 20 个六倍电频周期；保存时序、Ia/Ib/Ic、Id/Iq、角度、母线与实际输出，记录相电流和、RMS、峰峰值及频谱峰。
判别依据：重复工况下主峰随 `6*f_e` 移动才支持死区相关假设；随机尖峰或相电流和异常优先检查采样，固定频率振荡优先检查环路与机械。
得到该证据后再确定单一补偿 A/B 条件和通过阈值，不能预先宣称降噪；未得到新判别信息停止扫参。
