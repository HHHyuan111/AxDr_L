## RTT 使用要点

- 看日志：J-Link 软件包自带 JLinkRTTViewer.exe（未安装则装 SEGGER J-Link Software Pack），
  或 Keil 的 View → Serial Windows → RTT Viewer（版本支持时）；连接后选设备、搜 "AxDr RTT log" 即可。
- 预期上电输出：banner → adc started → foc init done → current offset done →
  param restore done → fast loop enabled（卡在哪一步一目了然）。
- 只允许 MAIN 上下文调用 rtt_log_*；快环调试仍走 debug_snapshot / cycle_record / 上位机波形。

- **_RAM_FUNC**：现有使用点全部位于 20 kHz RT 链上（采样/换算/算法/主链/快照/周期记录），

  common.h 包含之；MATH_ 前缀名已全部退役。
