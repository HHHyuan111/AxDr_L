## 0. 命名决策记录（2026-10-03，用户选定）

| 决策 | 结论 | 说明 |
|---|---|---|
| 框架前缀 | **无框架前缀**（沿用模块前缀风格） | 文件名不带框架前缀（math_const.h / ret.h / fault.h）；类型名=模块名前缀（encoder_type_t 先例）；函数=模块_动作。风格基准：简洁缩写达意，设计目的写在文档 |
| 数学常量 | **MATH_PI / MATH_2PI / MATH_SQRT3 系列** | 与 math.h 的 M_PI、CMSIS-DSP 的 PI 零冲突；禁 #define M_PI 等标准名 |
| API 返回码范式 | **务实极简** | 默认 void；只有可能失败的函数（初始化/IO/配置读写/参数设置）返回 ret_e（RET_OK/RET_PARAM/RET_BUSY/RET_UNSUPPORTED/RET_IO），调用方必须检查 |
| 故障位图 | **ERR_OC / ERR_OV / ERR_UV / ERR_OT_MOS / ERR_ENC / ERR_COMM_LOST / ERR_CONFIG** | 类型 fault_t，头文件 fault.h；检测方置位、Drive 处置、显式清除 |

**工作方式**：今后命名/接口类决策，先调查参考项目真实惯例（核实出处），整理 2-4 个带证据的选项交用户选择，结论记入本文档。

## 1. 参数放置：类型的家在算法，值的家在配置

| 参数种类 | 类型/定义放哪 | 值放哪 |
|---|---|---|
| 可调参数（要调/要存/上位机可读写） | **算法自己的 .h**（cfg 结构体，只定义类型不放变量） | **统一配置** motor_cfg_t 中一块 + 默认档案一处 |
| 物理常量（永不调） | 算法 .c 内 `static const` | 不存 |
| 标定/板级量（换板换电机才变） | 板级/标定头文件 | 配置的标定束 |

理由：持久化/上位机读写/版本迁移需要统一入口（值必须集中）；模块内聚要求类型跟着算法走
（改一个算法不动公共头）。两全 = 上表。

## 2. 新增算法固定模板

```c
/* ============================================================
 * algorithm/adrc_core.c —— 一阶 ADRC 核心实现
 * 来源：韩京清 ADRC / 参考实现出处
 * 单位：输入输出均 SI；ts 为调用周期 [s]
 * 上下文：可在 RT(20kHz) 调用；无动态内存；无硬件依赖
 * ============================================================ */
#include "adrc_core.h"

void adrc_init(adrc_t *a, const adrc_cfg_t *cfg);   /* 清状态、存参数引用 */
void adrc_reset(adrc_t *a);                          /* 积分/观测器状态清零 */
float adrc_tick(adrc_t *a, float ref, float fdb, float ts); /* 单步，唯一每拍入口 */
```

三件套固定：`init / reset / tick`。tick 是唯一每拍调用的函数；所有状态在对象结构体里。

## 3. 新增算法八条自查清单（提交前逐条勾）

1. 文件位置：纯核→algorithm/，控制壳→control/，传感器类→device/
2. 命名：类型 `<名>_cfg_t`/`<名>_t`，函数 `<名>_init/reset/tick`，文件全小写下划线
3. 零全局变量：状态全在结构体，函数首参为对象指针
4. 零硬件依赖：.c 不 include 任何 target/驱动头（grep 自查）
5. 每个字段带单位注释：[A] [V] [rad/s] [1/s]
6. 三件套齐全（init/reset/tick）
7. 配置类型已导出 + 默认值已加进默认档案（含来源注释）
8. 主机单测 ≥1 用例 + 一条数值基准（可用录波数据对拍）

## 4. 上位机/协作规则

- 提交信息格式：`<层>: <一句话>`（如 `algorithm: 新增 ADRC 核与数值基准`）
- 新算法 PR 必须附：单测结果 + 数值基准对比图（可与录波对拍）
- review 重点 = 八条清单 + 插槽落位正确性，不重审格式（03 号已管）
