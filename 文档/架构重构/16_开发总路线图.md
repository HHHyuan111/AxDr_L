# 开发总路线图（任务地图）

> 2026-10-03。本文是唯一任务总览：从当前状态到 v1.0 的全部阶段、产物、验证与标签。
> 执行原则：一次一层，每层「定契约→搭骨架→搬值→验层→提交」，资源曲线不允许单调上涨。

## 0. 三个库的角色（铁律）

| 库 | 角色 | 纪律 |
|---|---|---|
| **A** = AxDr_L dev 分支 | **唯一开发线**（新架构） | 所有新开发只进这里 |
| **B** = AxDr_App-沉沙ABZ | **只读基准**（新电机三闭环+上位机已验证） | 冻结后不改；只从中"搬值与行为基准"，不搬结构 |
| 工作区文档/脚本 | 规范与工具 | 冻结文档拷入 A 仓库 |

### 0.1 现有目录 → 冻结层名映射（防止两套称呼）

| 冻结层名 | 对应 dev 现目录 | 说明 |
|---|---|---|

## 3. 每层固定循环（P1-P7 通用）

1. 定契约：头文件 + 每字段单位/方向/写者注释 → 评审
2. 搭骨架：空实现 + 主机测试接线
3. 搬值：从 B 提取已验证数值/时序/公式（对照 B 的 docs 实施记录，如 ADC 时序核查、FPU/中断嵌套栈核查）
4. 验层：主机测试 + 依赖检查 + 全量编译 + build_measure 资源快照（对比上阶段不许涨）
5. 提交 + 打标签；关口阶段另跑硬件对照（B 曲线为基准，参数不允许漂移）

## 4. 贯穿纪律

1. A 是唯一开发线；B 只读
2. 每阶段一个标签；回退点清晰
3. 资源预算表（15 号文档）强制生效，超标即停
4. 新代码落位查 11 号文档插槽表；动两个以上插槽 = 停下讨论
5. 硬件三关口（①编码器②电流环③速度环）不通过不进下一层
