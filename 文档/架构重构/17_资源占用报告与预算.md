## 3. 四家开源怎么做资源管理（证据）

| 项目 | 机制 | 我们对应的吸收 |
|---|---|---|
| iFOC | `MEASURE_TIME`/TaskTimer 包每个 RT 任务，实测约 1µs 开销 @170MHz；task_times 常驻电机对象 | R3 的 ISR 耗时测量进 debug_snapshot 常驻字段 |
| ODrive | **每条线程栈大小是配置项**（stack_size_axis/usb/uart/startup/can/analog）+ 系统统计上报 | 栈大小进 board 配置 + 快照报水位 |
| VESC | 每线程 `THD_WORKING_AREA(名字, 字数)` 显式声明；配置缓冲用**内存池**（mempools）而非堆 | 缓冲区=编译期定长+预算表；禁堆 |
| SimpleFOC | 无（教学库定位） | 反面参照：不做资源遥测，产品化必补 |

共识：**资源当一等公民**——栈是配置、耗时是遥测、缓冲是定长池。R1/R2/R3 是这套思路
在裸机单栈环境下的等价物。

## 5. 资源规则（冻结提案，即《15_资源与栈规范》摘要）

**R1 编码禁忌（算法开发者只背这 6 条）**：RT 内禁 malloc/printf/递归/无界循环/flash 写/LCD/SPI 长传；局部数组 >64B 改 static；缓冲大小必须来自配置常量过预算表；大表挂编译开关；新函数进 RT 链前测一次 ISR 耗时；链接脚本不擅改。

**R2 机器自动查**：`-fstack-usage` + 调用链深度 vs 栈大小；堆=0 断言；map 报告 vs 预算表；grep malloc|printf 于 control/drive。

**R3 上板体检（10 分钟）**：栈油漆法水位；DWT 周期计 ISR min/max；CPU 负载 = 周期数/8000。三项进 debug_snapshot 常驻字段，VOFA 永久可见。

**预算表（冻结提案）**

| 区 | 预算 | 当前实测 |
|---|---:|---:|
| RAM 框架核心（bss+data） | ≤ 40 KB（2026-10-06 修订：P8 辨识/MIT/SMO 上下文入场，原 24KB 线已破；不含 `_user_heap_stack` 栈预留） | 36.2 KB（dev@a989dca，含 g_diag 8.0K） |
| RAM RamFunc 代码 | ≤ 8 KB | ~6.5 KB |
| RAM 栈 | 8 KB | 已配（ld+startup 0x2000，O2 执行；R3 油漆法复核后可回调） |
| RAM 余量 | ≥ 40 KB | 约 84.6 KB（131,072 − 36,228 − 栈 8,192） |
| Flash 框架+算法 | ≤ 128 KB | 74 KB（去字体/USB） |
| Flash 字体/表 | ≤ 32 KB | 13.3 KB |
| Flash 余量 | ≥ 256 KB | 现约 437 KB |
| RT ISR 耗时 | ≤ 25 µs（50% 时间片） | 待上板实测（R3） |

## 6. 给资源可视化工具的数据说明

数据文件：`build/rpt/resources.json`（由 `scripts/build_measure.sh <工程根> [输出路径]` 生成）。
Schema：

```json
{
  "meta":     {"build": "gcc10.3 -Os", "elf": "路径"},
  "sections": {"text": 59376, "rodata": 14616, "data": 12696, "bss": 18960},
  "ram_top":  [{"addr":"20005ae0","size":8392,"type":"B","name":"g_diag"}],
  "code_top": [{"addr":"08003c68","size":2492,"type":"T","name":"HAL_PCD_IRQHandler"}],
  "rodata_top":[...], "ramfunc_top":[...],
  "stack_top":[{"bytes":168,"fn":"diag_start_job"}]
}
```

可视化建议：①总量仪表（Flash/RAM/RT 时间片三条，对照 §5 预算红线）②RAM Top 条形图
（点击符号显示归属模块）③栈 Top 列表 ④多次构建的历史对比（把 json 按日期存档即可画趋势）。

## 7. 复测方法

```bash
bash scripts/build_measure.sh /path/to/AxDr_L/firmware/AxDr_App
# 输出: build/rpt/{AxDr.elf,AxDr.map,obj/*.su,resources.json}
```

注意：本机 gcc 10.3 不支持 `--no-warn-rwx-segments` 选项，脚本已去除该选项；与
CMakePresets 的 Release 配置等效（同为 -Os + gc-sections）。
