# 26 关口③验收手册——速度环闭环（P6 产物）

> P6 固件要求：本提交（对齐验收判据版）之后构建。前置：关口②已关闭（24 号）。
> 理论依据：对齐判据 s=√(−2·ln R̄)（循环统计学，SciPy circstd/R circular 同式）；
> 对齐方法 = MathWorks Ld Estimator/SimpleFOC alignSensor/B 库同款（d 轴定场拉零）。

## 1. 本次固件新增（相对关口②版）

- **对齐验收双判据**：①角度收敛 R̄≥0.99（≈8.1° 电角标准差）②电流建立 |fb.id|≥0.8×指令。
  任一不过 → 置 enc_err 故障、拒绝对齐结果（错误零点闭环比不运行危险）。清故障后
  重新 START 可重试。**若上机时 START 后 fault.all≠0 且转子没吸合——这就是判据在
  保护你**，回报现象即可。

## 2. 速度环操作序列

```
① req = 1 → 转子吸合（1.5s 对齐）→ state=2(RUN)
② g_foc.mode.debug = 4        （spd_curr_cl 速度模式）
③ 阶跃序列（每次间隔 2~3s，g_foc.ref.spd_r 单位 rad/s）：
   52.36  → 0 → -52.36 → 0    （±500rpm）
   104.72 → 0 → -104.72 → 0   （±1000rpm）
④ 全程录波（建议 J-Scope 100Hz~1kHz）：
   g_foc.fb.spd_r（滤波速度） g_foc.ref.spd_r（若有通道）
   g_foc.fb.iq（速度环输出电流） g_debug_snapshot.abz_spd_raw（原始测速）
   g_foc.fb.pos_r（多圈）
⑤ 结束 req = 0
```

⚠ 首次正向阶跃注意方向定义：dir=-1 下 ref.spd_r 正值对应的物理转向以实机为准，
确认后在本文档"方向定版"处回填。

## 3. 通过判据（B 库验收同口径：参数强一致 + 行为形态）

| # | 判据 | 量化 | 说明 |
|---|---|---|---|
| 1 | 阶跃跟踪 | 稳态误差 <5%（500rpm 段 |Δ|<2.6 rad/s） | 参数已与 B 逐位锁定（test_motor_chensha），行为应同形态 |
| 2 | 稳定性 | 无持续振荡/啸叫；超调可视但不发散 | 联轴固化 Kp/Ki 在 B 库实测收敛 |
| 3 | 对称性 | ±52.36 / ±104.72 行为一致 | |
| 4 | 限幅 | fb.iq 峰值 ≤8A；速度不超过 335 rad/s（超速保护自动触发则记为保护行为非故障） | |
| 5 | 滤波链健康 | fb.spd_r 平滑、abz_spd_raw 允许毛刺（200Hz LPF 前） | 测速链关口①已验 |
| 6 | 停机 | req=0 → PWM 关断自由滑行，速度自然衰减 | |

**方向定版**（实机确认后回填）：ref.spd_r=+52.36 对应物理 __ 时针（从轴伸端看）。

## 4. 选修：ibw 在线整定（不阻塞验收，默认不动 B 定版 4000）

24 号注记：电流阶跃 1.8ms/16% 超调（阻尼≈0.55）。如想更稳：
```
RUN 且 curr_cl 模式下，Watch 在线改：
  g_foc.id_pi.kp = 0.0001037615 * 3000   (ibw=3000)
  g_foc.id_pi.ki = 0.105125    * 3000
  g_foc.iq_pi 同步同值
→ 重做 id 2A 阶跃对比 → 更稳则回填 motor_config.h 的 CHENSHA_CURRENT_BW_RAD_S
```
注意：改的是运行时值，掉电回档案定版——试验满意再改宏重编译，保证"值有唯一家"。

## 5. 验收结果记录要求
