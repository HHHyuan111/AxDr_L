## 2. 0x2B 最终协议定义

- opcode：`AXDR_OPCODE_GET_FIRMWARE_RESOURCE = 0x002B`
- capability：`AXDR_CAPABILITY_FIRMWARE_RESOURCE = (1u << 28)`（已在 GET_PROTOCOL_INFO 广播）
- 请求：**空载荷**；应答 `ACK_ACCEPTED`；payload **固定 80 字节**，小端序，packed，固定偏移如下：

| 偏移 | 字段 | 类型 | 说明 |
|---|---|---|---|
| 0 | schema_version | u16 | 恒 1 |
| 2 | payload_size | u16 | 恒 80 |
| 4 | project_id | u32 | 0x00000001（AxDr_L） |
| 8 | target_id | u32 | 0=AxDr(Release) 1=AxDr-Debug |
| 12 | build_id | u32 | 每次构建唯一；0=未产包构建 |
| 16 | target_name[16] | char | "AxDr" / "AxDr-Debug"，0 填充 |
| 32 | boot_id | u32 | flash 持久上电自增；0=尚无记录 |
| 36 | uptime_ms | u32 | fast_seq/20；回绕用差值比较 |
| 40 | reset_reason | u8 | RCC->CSR 位 25~31，启动锁存，查询不清除 |
| 41 | stats_valid | u8 | 0=快环未跑够一拍，统计字段无意义 |
| 42 | reserved | u16 | 恒 0 |
| 44 | stats_seq | u32 | 每次查询自增（与 irq_count 无关） |
| 48 | irq_count | u32 | 快环执行总拍数（次） |
| 52 | irq_last_cycles | u32 | 最近一拍 ISR 耗时（核周期，160MHz 下 1 周期=6.25ns） |
| 56 | irq_max_cycles | u32 | 历史最坏一拍 ISR 耗时 |
| 60 | irq_overruns | u32 | 单拍 ≥ 周期 的拍数 |
| 64 | irq_gap_count | u32 | 间隔 >1.5 倍周期 的次数 |
| 68 | adc_overruns | u32 | ADC 溢出次数 |
| 72 | core_clock_hz | u32 | 内核时钟 Hz |
| 76 | stats_capability | u32 | bit0=IRQ 计时（已支持）；其余 0=不支持，灰显 |

## 9.5 产包一致性修复（交接 v2 说明）

初次交接后发现双 target 共用 axdr_build_id.h 导致产包身份可能串 target（Debug 构建覆盖头文件后，
Release 产包读了 Debug 的身份）。已修复：build_resource_package.sh 增加一致性硬门
（头文件 target ≠ 请求产包 target 时拒绝产包），并已重建 Release、重新产包、反汇编验证
build_id 确实以 movw/movt 立即数嵌入镜像（0x056E1B00 × 3 处）。本交接包所有身份值均为
修复后的最终值。
